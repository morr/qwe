# 71 — Демон-орды: фон + волны (план ×10, фаза 4)

2026-11-21, звено №50, ветка pop50 (4 коммита, ff на 764d8c2f), Тула 200k живьём.

## Что сделано

`demon/horde.rs` — расписание волн поверх фонового спавна: раз в затишье
(`wave_every` с разбросом ±25 %) на случайном проходимом тайле открывается очаг,
из которого за несколько тиков выходит `wave_size` демонов порциями по `wave_len`
за тик. Кап у источников общий (`DemonStyle::cap` — дефолт 3500, потолок слайдера
5000), очередь выпуска считается обязательством перед капом (`HordeSchedule::pending`,
`tick_spawner` проверяет `spawned + pending`), частичная волна легальна, полный
кап вырождает волны в пустые затишья (трейд принят владельцем при ревью плана).
Каждый параметр волны — из чистого потока её номера `stream(seed, Demon,
HORDE_WAVE_KEY + wave_index)` (ключи — верхняя половина пространства ключей,
от 2⁶³), поток живёт один вызов `plan_wave` — пин «то же зерно — то же
расписание» без приложения. Демон несёт `WarpOrigin` (портал — у born-у-портала,
очаг — у волнового) и блуждает «от происхождения»; для порталальных демонов вектор
`away` и число бросков не изменились (пин эквивалентности). Фон ускорен: интервал
дефолт 1.0 → 0.03 с (3500 демонов за ~110 сим-с — директива владельца «кап за
1–2 сим-минуты»), кап 350 → 3500. Реплей-двор гоняется с волнами (дворный
`HordeStyle` 12/1.0/4 в `replay_app`) — `a_restart_replays_the_run` покрывает
расписание и выпуск. `sim/horde_ms` — новый разрез; `Census.wave` — счёт волн,
едет в строку спайк-отчёта.

## Пины

`the_same_seed_plays_the_same_wave` (чистое расписание без приложения),
`wave_positions_land_on_passable_tiles` (двор фикстуры),
`zero_wave_size_silences_the_horde_and_drops_the_release`,
`a_wave_releases_only_the_free_room`,
`a_portal_demon_carries_the_portal_as_its_warp_origin` +
`the_warp_origin_stears_the_first_wander_target` (эквивалентность),
`every_spawned_demon_advances_the_counter_exactly_once` расширен на смешанный
источник; реплей-двор с волнами — все четыре пина отпечатков.

## Остатки

- Полный 30-мин прогон с волнами (критерий Ф3 в формулировке плана) — не гнан.
- Слайдер фона владельца: сохранённые настройки перебивают дефолт 0.03
  (у владельца interval 1.0 стоял в settings.toml — кап заполняется за час).
  Дефолт применяется только на reset — осознанное поведение префов, не баг.
- Ф6 (экономика демонов на 3500) — по данным этой записи: acquire не узкое
  место, кандидаты Ф6 из плана пересматривать по её собственным замерам.
