# NOTES — обзор №28 (угол: краевые значения стилевых ресурсов — что может уронить живое приложение; два краша закрыты клампами на чтении)

Задача: двадцать восьмое звено цепочки — оптимизационная форма (директива
владельца), меню пусто — угол свой. Первый кандидат («разрез кадра: куда
уходит время Update») снят сверкой с перф-журналом: серия 50–57 владельца уже
закрыла рантайм кадра целиком (tick/post/gap/рендер/спайки/GPU/архетипы,
img2 — idle, конвейерные и движковые оси off-limits), а «Углы» этого не
отражали — README журнала стал обязательной сверкой перед «свежим»
перф-углом (урок в постоянном разделе «Рабочее меню»). Принятый угол:
слайдеры панели ограничены диапазонами, но BRP и старый settings.toml пишут
в ресурс напрямую; по конвенции «ресурс клампит на чтении» (эталоны —
RoadShape, RoadPaintStyle) каждый стилевой ресурс обязан держать мусор.
Свип всех BRP-пишемых ресурсов + живые пробы.

## Найдено и влито (ветка perf28, 3 коммита 8493c99c / 74516364 / b96809f3 →
## ff master b96809f3; check.sh OK дважды; cargo check --lib главного
## чекаута после ff — OK)

Два краша воспроизведены живо на master и закрыты:

1. **`SimSpeed.requested = -5` (или NaN) → рестарт умирает.** Вход в мир
   копирует requested в `Time<Virtual>` напрямую (`on_world_started` — на
   каждом рестарте и смене города), `set_relative_speed` паникует («tried
   to go back in time» / «infinitely fast»). Регуляторный путь безопасен
   (`advance_speed` клампит target в MIN..MAX) — до рестарта мир молча полз
   на effective=0.1. Фикс: `sane_requested` в обоих читателях (governor +
   on_world_started): отрицательное и NaN — ноль «стоять», +inf клампится в
   потолок как раньше; пин `a_garbage_requested_speed_does_not_sink_the_world_start`.
2. **`DemonStyle.interval = -1` → первый тик спавнера умирает.**
   `Duration::from_secs_f32` паникует на отрицательном и переполнении
   (1e30 тоже); cap без потолка заселял бы мир до исчерпания ресурсов.
   Фикс: аксессоры `interval()`/`cap()` со шкалами слайдеров
   (RoadShape-паттерн), таблица-тест.
3. **ConiferNoiseStyle: wavelength=0 → 1/0=inf и NaN в позициях шума;
   octaves без потолка → фриз пересэмплирования** (живо не пробовался —
   фриз неоткатываем; петля `conifer.rs::sample`, проба 4e9 на фикс-версии
   проходит мгновенно). Фикс: четыре аксессора
   `wavelength()/octaves()/lacunarity()/persistence()` — clamp + is_finite,
   `sample()` читает только через них.

Живая верификация: на фикс-версии все три пробы (interval=-1, octaves=4e9,
requested=-5 + RestartEvent) — приложение живо, panics=0. Персистентность:
settings.toml пишется на выходе — BRP-краш умирает до записи, boot-лупа из
BRP-пробы не случится; мусор из файла теперь безвреден тоже (клампы читают
и стартовые значения). Ресурс хранит сырые поля (4e9 видно в `res get`) —
как у RoadShape, кламп только на чтении.

## Чистые зоны свипа (негативы с основаниями)

- Остальные стилевые ресурсы паник-математики не имеют: HumanStyle
  (body_radius/spread), SeparationStyle (sidestep/backstep/hold — f32
  множители, не Duration), DemonStyle.speed/lunge, CarStyle.occupancy
  (f32→usize сатурирует), TreeStyle.density (min-кап LOD), conifer_share
  (0 %/100 % special-cased), RoadPaintStyle/SurfaceStyle — шейдерные
  униформы. Мусор даёт визуальный/поведенческий мусор (демоны ходят назад,
  пешки нулевого радиуса), не краш — не клампится, триггер ниже.
- Enum-ресурсы (BuildingHeightMode, NavtileBase, PathfindingAlgorithm,
  TreeShape) — BRP-запись мусорной строки даёт чистую ошибку отражения.
- DemonSpawner — состояние мира, не настройки; сбрасывается на рестарте.

## Остатки и уроки (следующим звеньям)

- **Триггер на остаток**: жалоба владельца на «сломанный» вид от ручных
  значений или правка любого из потребителей списка чистых зон — клампить
  его поля тем же паттерном (механика одного коммита).

  перф-журнала закрывает рантайм кадра целиком (50–57); сверяться до того,
  как угол принят, иначе «свежий» угол оказывается паханым (полчаса живого
  замера в мусор).

  (Edit-пути были главночекаетными) — `git status --short` после первой
  правки поймал, правка перенесена, главный откачен. Правило живо.
