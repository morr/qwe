# Запись 3 — Разрез тика и кадра (временные probe2-диагностики, откатаны)

Статус: замер.

Горячее состояние (requested 10, effective 6.9, Tula): тик 2.06 мс; измеренные
подсистемы — panic 0.2, flee 0.15, acquire 0.15, snapshot 0.14, move 0.13, chase 0.05,
separation 0.05, spatial 0.04 ≈ 0.9 мс. Кадр-конвейер (Update): **dispatch 0.49 мс**
(проход по ~19–20k стоящих заявок каждый кадр), interp 0.32, slots 0.16 (Added-скан
архетипа заявок), listen 0.15.

**Фикс из разреза:** интерполяция не работает на паузе — лерп по всем
пешкам выдавал те же значения и тратил 0.15–0.3 мс кадра впустую
(`movement/systems.rs`, ранний выход при `is_paused`). Плюс
инфраструктура: `tick spike: N ms for M ticks` в лог при
`QWE_PERF_FRAME_SPIKES=<ms>` — секундные средние размазывают всплески.

**Открытая гипотеза.** В эндшпиле (350 демонов, 12.6k трупов, 7k людей)
тик вспыхивал до 41 мс при подсистемах <1 мс — незмерённый всплеск, вероятно
волна archetype-передвижек от массы ответов pathfinding (174 ответа/кадр) или массовых
деспонов. Требует отдельной охоты: у спайка был разовый характер, мир уже утих.

**Запаркованные кандидаты** (выгода против риска): инкрементальный кеш
стоящих заявок диспетчера (−0.4 мс/кадр, но правка тонко-упорядоченного конвейера),
замену Added-скана слотов на обсервер (−0.16 мс/кадр).
