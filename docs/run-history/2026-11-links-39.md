## Найдено (БЕЗ КОММИТОВ — правки кода угол не потребовал; живая проба на ворктри-инстансе, его .settings — песочница)

- **Библиотечный путь (bevy-settings 0.20.1) устойчив к пользовательским
  данным**: битый TOML → `error!`-лог и `None` (дефолты), валидный
  не-таблица → тот же путь, пустой файл — валидная пустая таблица вовсе
  без ERROR; запись — temp-файл + rename (атомарно); неизвестные поля
  игнорируются, поля не тех типов тихо остаются дефолтными
  (TypedReflectDeserializer → Err → skip). Единственная паника
  (build_settings_registry) — программная ошибка «группа без Default»,
  у qwe закрытая register_pref'ом и guard-тестом.
- **Карта групп/ключей коллизий не имеет** (сверена с derive-макросом +
  `#[settings_group]`): одна группа на ресурс; «world»/«debug»/
  «navigation» — слиянные по ключам (seed/city/deterministic; девять
  тумблеров; navtile/algorithm); единственная разделяемая группа —
  «camera» (`position_mode` + `SavedCameraView{position,zoom}`), при
  записи сливается per-field, поля не пересекаются — задокументировано
  в коде (camera.rs:97–99). Дефолтное имя без атрибута — pascal→snake:
  InspectorHighlight → `inspector_highlight`, совпадает с док-комментарием.
- **Круговорот settle-пар закрыт осознанно**: SunStyle/RoadShape — сами
  группы (в файл сериализуются напрямую), SunOnMap/RoadShapeOnMap — не
  группы, только триггеры записи; на буте `seed_sun`/`seed_road_shape`
  (Startup, до построения материалов) копируют сохранённые значения в
  копии — ползунки показывают сохранённое, карта собрана с ним;
  `set_if_neq` не считает дефолтный запуск правкой.
- **Живая проба** (worktree perf39): мусор, TOML-не-таблица, пустой файл,
  частичная порча (не-те типы + несуществующий вариант City + мусорное
  значение в валидной группе) — все четыре бута дошли до Live, panics 0;
  ERROR-лог только на двух первых; per-field самолечение подтверждено
  BRP-ом (elevation = 80 применился рядом с испорченным azimuth,
  antialias = false применился, мусорные значения вернулись к дефолтам);
  при выходе файл перезаписан валидным — цикл самолечения полный.
