## Найдено (ветка perf31 — БЕЗ КОММИТОВ, правки кода угол не потребовал)

- **Статика: движок деспаунит батчем сам.** bevy_state 0.20.1
  (`state_scoped.rs::despawn_entities_on_exit_state:177`) на выходе из
  состояния ставит один `commands.despawn_all_where::<&DespawnOnExit<S>>` —
  per-entity цикла нет, ускорять нечего; цена присущая (архетипный вынос
  сущностей).
- **Живой разрез шва (бинарь worktree, QWE_PERF_PHASE_SPIKES=30; ранние
  замеры сессии чистые — сошлись с базами записей 61–63).**
  - **Париж→Тула, шов 1.25 с** (reload 03.665 → warmup 04.917): деспаун-рамка
    перехода trans **29.9 мс** (frame 32.6), загрузка 741 мс (снапшот 17.9 +
    fill 26.8 + prune 113 + лейны 714), рамка входа **248 мс** (trans 89.6 —
    спавн-флеш + update 79.5 + post 78.4), прогрев 0.46 с. Деспаун = 2.4 % шва.
  - **Тула→Париж, шов 4.38 с**: деспаун-рамка ниже порога 30 мс; загрузка
    ~2.6 с лейнов (fill 137 + gates 178 + prune 82), рамка входа **660 мс**
    (trans 432.5 + update 114.8 + post 112.5 — территория записей 12/23/57),
    прогрев 1.23 с. Деспаун < 1 % шва.
  - **Рестарт R (на паузе)**: строка «restart: despawning 20017 scene
    entities» — и ни одной рамки ≥30 мс до resume на фоне, спайкующем
    100–400 мс каждые пару кадров: деспун+респаун 20k пешек целиком ниже
    порога (в существующие архетипы, без ассетов — в отличие от входа в мир).
- **Вердикт: дефекта и стены нет, правки не требуются.** Деспаун шва — 30 мс
  на фоне известной закрытой территории (лейны загрузки, рамка входа,
  прогрев); дифф нулевой, check.sh не гонялся. Перф-вердикт: код не менялся —
  цены нет, угол диагностический.
