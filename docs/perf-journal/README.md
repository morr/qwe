# Журнал производительности qwe

Детальная история охоты за performance issues: гипотезы, замеры, фиксы, опровержения.
Краткий индекс — артефакт-журнал: <https://artifacts.spacehubstore.com/a/qwe/qwe-perf-journal>.

## Структура

- `NN-<slug>.md` — записи истории, по одной на запись журнала. Файл каноничен: в нём
  полное описание, в артефакте — одна строка и путь сюда.
- `planned/NN-<slug>.md` — спецификации запланированных доработок. Пишутся до работы,
  рассчитаны на агента, который заезда не видел: цель, доказательства с числами, дизайн,
  шаги, верификация. Взял в работу — работай по файлу, а не по строчке в индексе.

## Правило ведения

Новая запись (замер, фикс, опровержение) — сначала файл `NN-<slug>.md`, затем строка
в артефакте (get_artifact → правка → update_artifact с expectedRev). Запись без файла
не считается опубликованной: артефакт хранит только индекс.
