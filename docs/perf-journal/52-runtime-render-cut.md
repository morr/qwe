# Запись 52 — разрез рендерной стороны кадра: плато; рендер bevy 0.20 пайплайнен (extract ~26, render-CPU ~55–84 м/с — всё ниже планки), img2 — idle executor'а, не CPU

Статус: разрез-заезд 42 (`planned/40-runtime-render-cut.md`). Фикса нет —
плато. Worktree-пара `perf42-base` / `perf42` @ `75e9a1e8`, кеш
`assets/osm` с mtime без `paris_*.bin` (снапшот написан холодным
прогоном base-стороны), target посеян. Инструментация — временный патч
(`/tmp/perf42-temp.patch`, не коммитился, откатан): кадровые стены +
`tick cut` + `cmd cut` из патча записи 41 (пост-пробы UI выброшены —
территория 41 закрыта) + новая рендерная часть: **обёртка
`take_extract`/`set_extract` вокруг `SubApp::extract`** и
exclusive-штампы extract-внутренностей и фаз RenderSystems под
`QWE_PERF_CUT_PROBES=1`/`QWE_PERF_CUT=1`.

**Было.** Запись 51 закрыла рантайм при планке ~100 плато и оставила
рендерную сторону кадра без секундного разреза: inter 10.4 м/с («extract
+ рендер + сон vsync», запись 50) и скобка `extract_2d_meshes` 0.31
мс/кадр — единственный известный кусок extract (~19 м/с). Вывод штампов
записи 35 (`frame_phases.rs`, 14 фаз RenderSystems) стоял: печатал только
на спайк-кадрах входа, steady-state не снимал.

**Ключевая поправка к раме — рендер пайплайнен.** Registry: 0.20 несёт
`PipelinedRenderingPlugin` в DefaultPlugins — Render-расписание идёт на
отдельной render-нити (в sample она видна как «Render thread»), extract
(`update_state` + `entity_sync_system` + `ExtractSchedule`) — на
main-нити **после завершения обоих** (докстринг плагина). Сегмент `inter`
10.3 мс/кадр = extract 0.44 + ~9.9 мс парка main в event loop (дисплейный
link пейсет 60 Гц) — не «extract + рендер + сон» одной кучей, как стояло
в записи 50; render-нить живёт параллельно и заполнена собственным
слотом. Формула кадра: main работает ~7 мс (pre..post), спит ~9.7;
render-нить busy ~8 %, спит ~86 %.

**База заезда** (холодный + 3 тёплых прогона, свежие процессы, холодный
первый не в медиану, 32 с между, тёплые перезагрузки Парижа, парсов 0 —
снапшот-хит, `panicked`/`ERROR` 0): скорость 30, actual ≈ 15.0,
TickDebt 0/owed 0; инвариант телеметрии сошёлся бит-в-бит во всех четырёх
(20000). Сим-контекст как в записи 51: тик 0.215–0.238 (16 тиков/кадр),
`cmd cut` fleerep 583–1144/с, to_moving 729–1350/с, chase 145–295/с,
panic 62–122/с, kill 13–31/с, spawn_d 0 (демоны на капе).

**Разрез рендера** (медианы тёплых прогонов; `frame cut`: pre 0.26,
trans 0.06, fixed 3.6, update 0.30, post 2.16, inter 10.3 — сумма 16.68 ≈
слот):

| кусок | мс/кадр | м/с |
|---|---|---|
| extract (`SubApp::extract` целиком — обёртка) | 0.41–0.45 | **26** |
| — окно `ExtractSchedule` (PROBES-прогон) | 0.40 | 24 |
| — pre-extract sync (обёртка − окно) | ~0.03 | 2 |
| render-CPU (сумма именованных фаз без img2) | 0.92 | **55** |
| — apply 0.125, sort 0.30, specialize 0.17, prepare 0.13, erased 0.11, meshprep 0.03, pre3 0.04, render 0.004 | | |
| render-нить busy по sample (executor-драйв + culling) | ~1.4 | 84 |
| img2 (скобка `prepare_assets::<GpuImage>`) | 15.9–16.1 | — idle |
| main-сон в event loop (inter − extract) | 9.9 | — сон |

- **extract 26 м/с** — ниже планки; персональные скобки (e2d 0.36, cams
  0.17, core2d 0.19, vis 0.20, ui 0.35, uite 0.42) перекрываются —
  concurrent системы, стены вверх (урок 51): атрибуция внутри окна
  скобками не делается, и не нужна — целое окно 24 м/с.
- **render-CPU 55 м/с по фазам, 84 м/с по sample** — размазан: крупнейшая
  именованная фаза sort 0.30 ≈ 18 м/с; добавка sample — executor-драйв
  render-нити и `check_visibility_cpu_culling` (par_iter в стеке) —
  движковые, концентрации нет.
- **img2 — idle, не CPU**: скобка держит весь слот, но `prepare_assets`
  в sample 0 сэмплов; render-нить 86 % в `cvwait` — парк executor'а
  между кадрами/задачами. Скобка фазы в пайплайн-кадре меряет слот нити,
  не работу.
- **Сон**: main 9.9 в event loop + render-нить в собственном парке —
  дисплейный пейсинг, не рычаг (запись 35: uncapped present на Metal
  нет; здесь уточнение — wait размазан по двум нитям, а не сидит в
  present).

**Полнота разреза** (четыре сверки): сумма frame cut 16.68 ≈ слот 16.7;
inter 10.3 = extract 0.44 + main-сон 9.9; extract: окно 0.40 + sync 0.03
≈ обёртка 0.43 (PROBES-прогон, без проб обёртка та же 0.41–0.45); render-
расписание: сумма фаз 16.9 = img2-idle 16.0 + CPU 0.92 (+разница с sample
— executor-драйв). Входной шторм в разрезе — известные классы (trans
7.5–8.0 флеш спавна; img2-сторм у лимитера байтов на входе — вот где
тогда ждала render-нить).

**Вердикт — плато рендерной стороны на планке ~100 м/с.** Все куски ниже
планки: extract 26, render-CPU 55–84 (размазан по движковому executor'у
и фазам), sync ~2; остальное — сон дисплея. Рентable-рычага нет:
масштабирует счёт извлекаемых/видимых сущностей (20k пешек — сама игра),
как и post в записи 51. Рендер-рычага нет. Рейтинг после заезда: рантайм при планке 100
закрыт целиком — сим 207 (структурный кап, 50), GAP 134 (сантехника,
51), post ~130 (движковый PostUpdate, 51), рендер (эта запись). Следующая
территория при снижении планки — только продуктовая: счёт извлекаемых/
видимых сущностей (LOD/мердж пешек — решения автора), либо смена темы
(джерки как юзер-видимые спайки, GPU-инструмент).

**Метод** (новое к методу записей 51):

- **обёртка `take_extract`/`set_extract` — точная внешняя скобка
  `SubApp::extract`**: не exclusive-система, executor не синхронизирует,
  стена не врёт (в отличие от probe-скобок); документированный паттерн
  bevy_app («take the Bevy default function… install your own instead
  which calls the Bevy default»);
- **пайплайн-рама кадра bevy 0.20**: `PipelinedRenderingPlugin` в
  DefaultPlugins — Render на своей нити, extract на main после обоих;
  `inter` кадрового разреза — extract + парк main в event loop, а
  render-нить имеет собственный слот; скобка фазы render-нити (img2)
  меряет слот нити — перед чтением таких стен проверять, где нить паркуется;
- **`sample` первым, скобки — после**: один 4-секундный сэмпл (render-
  нить 86 % cvwait, `prepare_assets` 0 сэмплов) опроверг «img2 — дорогая
  фаза» до того, как заезд потратился на её разрез;
- перегонка патча записи 41: пост-пробы UI выброшены (территория закрыта),
  кадровые/тиковые стены и счётчики команд перенесены как были;
- баш-цепочки длиннее 120 с рвать на шаги — дефолтный таймаут вызова в
  этой сессии 2 мин (один прогон дооборачивался вручную);
- `brp quit` — с проверкой `pgrep`; после всех гашений пусто.
