# NOTES — обзор №42 (угол: вся кешированная коллекция городов против полного пайплайна — офлайн navmesh_probe 13/13 + живой свит 18 загрузок; вердикт: коллекция переживает пайплайн целиком, инвариант населения бит-в-бит на каждом городе; правок кода не потребовалось, без коммитов)

Задача: сорок второе звено — обзорная форма (меню малых оптимизаций
исчерпано, №37–41). Угол — коллекция городов: цепочка верифицировала
Париж и Тулу десятками замеров, но ни одно звено не спрашивало,
работает ли каждый город коллекции целиком. master на старте 68331d22.

## Методика

Worktree perf42 (сид кеша rsync: 13 json + 2 снапшот-бина; target
засеян). Два прохода. **Офлайн**: `cargo run --example navmesh_probe --
<slug>` по всем 13 кешированным городам — фулл-парс + fill + калитки +
прунинг + полимеш, паника на любом шаге = находка. **Живьём**: Astar
сразу после бута (урок №15), свит 12 городов `res set City . '"<Variant>"'`
с ожиданием НОВОЙ warmup-строки, после каждой — `count Human Demon
CorpseTag` + `res get Telemetry`; затем цикл снапшота write→read
(повторная загрузка крупнейших городов) и визуальная проба трёх городов
скриншотами (Москва-центр, Берлин, Девилс-Лейк).

## Найдено

- **Коллекция переживает пайплайн целиком.** Офлайн 13/13 (парс,
  заливка, калитки, прунинг, полимеш — без паников); живьём 18 загрузок
  (13 городов + шот-переключения), ноль ERROR, ноль паников, ноль
  выживших сущностей. Инвариант населения `alive+killed+escaped==20000`
  бит-в-бит на каждом городе после каждой загрузки.
- **Калитки/прунинг офлайна = живьём бит-в-бит у всех 13 городов**
  (напр. калуга 751/23239, ростов 1024/231152, девилс 12/248261):
  navmesh_probe с дефолт-кнобами — точный оракул навмеша живого
  приложения, а дефолт-кнобы примера совпадают с кнобами настроек
  (k3.3_2_off). Базовые числа — в «Известные измерения».
- **Снапшот-цикл write→read закрыт на 11 городах, у которых бинов
  не было**: записи 1–33 МБ за 6–175 мс (берлин 33, москва-ц 25),
  ни одного сбоя записи; повторное чтение — все хиты без reject
  (берлин 305 мс, москва-ц 240–261 мс, девилс 20 мс). Бины перенесены
  в кеш главного чекаута (assets/osm gitignored, прун-свип их стережёт).
- **Warn-словарь свита — ровно три вида, все задокументированы
  кодом как норма**: `map meshing: N degenerate polygons skipped`,
  `building meshing: N degenerate…`, `polymesh: N seams stitched by
  fewer than two vertices` (stitch.rs: комментарий над warn — «вершине
  шва без пары у соседа стена, сшивать нечего»). Не встретились ни разу:
  `grid: box skipped`, `no clear spot for portal`, снапшот-reject,
  `warmup timed out`.
- Девилс-Лейк — вырожденный конец коллекции (3534 здания все без
  высоты, 0 деревьев/лугов/лэндьюза) — рисуется корректно и живёт;
  warmup 0.81 с — самый быстрый в свите.
- Warmup-окна свита 0.81–2.84 с (самый тяжёлый — калуга, 13688
  зданий/106212 деревьев); Париж на сид-снапшоте 1.27 с.
- Визуальная проба: Москва-центр (кремль, Василий Блаженный),
  Берлин (Шпрее, Музейный остров), Девилс-Лейк (американская сетка) —
  слои на месте, портал в центре, HUD здоров.

## Негативы, остатки и уроки (следующим звеньям)

- **Форма `res set` — три аргумента**: `res set City . '"Tula"'`.
  Двухаргументная запись из старых уроков (`res set City '"Paris"'`)
  врёт — скрипт отвечает «needs <Resource> <.path> <json-value>», свит
  молча ждёт несуществующую warmup-строку (10 минут свита выброшено).
  Урок записан в «Уроки живых замеров», старая строка поправлена.
- **Скриншот живьём: `shot` без аргумента, файл переносить руками** —
  приложение пишет в свой cwd (`screenshot.png` + `.small.png`),
  кастомный путь скрипт ждёт зря (30 с на попытку × 3).
- Свит-цикл 12 городов не влезает в foreground-таймаут 10 мин —
  запускать фоном сразу.
- 8 городов без кеша не пробовались (moscow_n/se/s/sw/w, ny, london,
  tokyo) — живая загрузка скачала бы выгрузку с Overpass; свит держал
  офлайн-дисциплину. Расширение коллекции — решение владельца.
- Pathfinding-очередь после warmup (~19.7k queued, answers 1.0/frame)
  — известный дизайн диспетчера (warmup раздаёт только экран), не
  дефект свита.
- worktree perf42 **правок не несёт** (ветка = master 68331d22),
  не помечен «сохранён» — удалить
  (`git worktree remove .worktrees/perf42 && git branch -d perf42`).
- Правок кода нет → check.sh не требовался; cwd-дисциплина: один дрейф
  cwd в ворктри после cp скриншотов (среда вернула обратно сама).
