«следующий уровень» записи 47 с изменившейся экономикой: вариант-а

perf12 по причине «лейн заборов дорог сам по себе (2.3–2.8 с)» — запись 63
срезала его до ~1.0 с, стеной whole set стал лейн дорог, основание гейта
исчезло. master на старте b0b469a5.
