# Запланировано 08 — дорожная дорожка prepare-потока: ступени обочин по потокам и фазы build_roads по ядрам (Париж)

Приоритет: **1** — после записи 19 дорожная дорожка — стена мешинга.

## Проблема

Тёплый старт Парижа (снапшот-хит) — 9.57/9.59 с (запись 19). Стену `build_world_meshes`
держит дорожная дорожка: 5.8–5.9 с за **обе ступени обочин в одном потоке** —
`build_roads` зовётся последовательно по ступени (`map/prepare.rs`), бенч одной
ступени — 3.26 с (`measure_roads`, ближняя ступень). Зданиевая дорожка после
заезда 09 — 2.3 с, полимеш 4.3–4.5, мелочь 1.2–1.3, заборы 2.8 — всё уходит в
тень дорожной, как только дорожки выравниваются.

Разбивки дорожной дорожки по стадиям ещё нет — это первый шаг заезда
(инструментированный разрез, как у зданий в записи 19: тогда разрез отделил
union 640 мс / кайму 436 от «своих» ~760 мс арок, которые без него были бы
приписаны union).

## Направление решения

От простого к сложному, с контрольной точкой после первого шага:

1. **Две ступени обочин — два потока.** В `prepare.rs` групп «дороги» — одна;
   ступени независимы: обе строятся от одной и той же финальной `MapData`
   (она к дорожкам финальна и не мутируется — гейты и состав деревьев уже
   отыграли), каждая собирает свои списки. Две группы вместо одной —
   стена дорожек 5.8–5.9 → ~2.9 с (max двух ступеней). `rebuild_roads`
   не трогается: пересборка стилем/солнцем/формой строит одну ступень,
   как и сегодня. Глобаль ширины полосы пишется до дорожек, как сейчас.

2. **Разрез фаз `build_roads`** — временные `eprintln` (снять до коммита):
   подготовка нарисованной сети (`Drawn::new`, узлы, оси, стежки),
   `Junctions::new`, `kerb_returns`, `medians::draw`, главный ленточный
   проход, краска, лоскуты, сборка слоёв (earcut). Ищем «свои арки»:
   линейные сканы по городу (прецедент — `arches_by_building` записи 19,
   760 мс на линейном поиске дома у прохода) и независимую по улице работу
   внутри ленточного прохода.

3. **Параллелизация независимых единиц** по прецедентам заезда 09:
   `in_parallel` (результаты в порядке входа — детерминизм не зависит от
   гонки), слияние сборщиков по клеткам через `MeshBuilder::append`
   (треугольники и фактуры в порядке), сетки `Grid` вместо линейных сканов.
   Кандидаты — то, что покажет разрез: улица ленточного прохода —
   независимая единица (фаза уже идёт в порядке заливки, порядок входа
   = порядок заливки), скругления и разрывы — тоже по узлам.

## Инварианты (не трогать)

- **Порядок заливки** — «узкие первыми, ведущие последними, по узлу»
  (`roads-junctions.md`): ленты, краска и клинья ложатся им; при
  распараллеливании порядок входа `in_parallel` = порядок заливки.
- **Чанки карты** (`LayerMesh::into_chunks`), порядок слоёв в `RoadBuild`,
  порядок `DrawnPieces` / `RutLines` / `TramTracks` — контракт семантического
  индекса и оверлеев.
- **Зерно от точки** (`map/seed.rs`): ничего в дорожной сборке не сеется от
  индекса улицы.
- **Чистота `build_roads` по карте** — перед шагом 1 проверить: две ступени
  строятся от одной `MapData` параллельно; любая мутация (гейты уже прошли,
  `composed_for` тоже) — не в этой функции. Если найдётся мутация — она и
  есть баг чистоты шва, правится до разъезда.
- **Пересборка живым солнцем остаётся дешёвой**: солнце оседает —
  `rebuild_roads` строит одну ступень (3.26 с бенча в худшем случае); шаги 2–3
  ускоряют и её, но регресса не дают.
- Инструменты по цветам слоёв и `references/roads-*.md` (скил osm-map) —
  карта инвариантов обочин/кербов; правки обочин сверять с ними.

## Шаги

1. Спека (этот файл).
2. База: 2 живых тёплых старта (снапшот-хиты, `caffeinate -i`,
   `QWE_PERF_NOAPPNAP=1`/`NOVSYNC`/`FRAME_SPIKES=30`) + бенч
   `cargo run --example map_meshing -- paris` в одном состоянии машины.
3. Разрез фаз (временные `eprintln`, до коммита) — сначала офлайн бенчем,
   потом подтверждение живым лейном.
4. Ступени обочин — две группы в `build_world_meshes` (+ тест в
   `prepare.rs`, что групп две и порядок ступеней сохранён).
5. Параллелизация фаз по результатам разреза (мелкими шагами, каждый с
   бенчем).
6. Верификация (ниже), запись 20, артефакт.

## Верификация

- Бенч: дорожная дорожка 3.26 с (одна ступень) → целевая цифра по разрезу;
  счётчики отчёта `RoadReport` бит-в-бит до/после (кроме архитектурно
  изменившихся порядков — тогда честная фиксация в записи).
- Живой тёплый старт: 2 базы + 2 правочных прогона, «map meshes: roads …»
  и «whole set in …» — стены упали, warmup в шуме (шторм плавает, записи
  15/19); строки `osm map:` бит-в-бит.
- Картинка: оффскрин-кадр плотного центра Парижа до/после (обочины, кербы,
  краска, кольца — та же геометрия), счётчик вершин дорожных слоёв в бенче.
- `world reload: N scene entities survived` — 0; `panicked`/`ERROR` — 0.
- tools/check.sh по изменённым файлам.
