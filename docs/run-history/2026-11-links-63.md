## Угол и что снято

- **Методика**: python-стрипп тестовых модулей с brace-matching → инвентарь
  550 сырых сайтов → 402 после фильтра тестовых файлов → **83 продакшн**
  (ловушка стриппера найдена на этом шаге, см. уроки). Классификация:
  бут/env → тред загрузки → тик/кадр, каждый сайт опасного класса — чтение
  в контексте.
- **Радиус поражения**: тик/кадр паника = смерть симуляции (не ловится ничем,
  кроме спроектированных tripwire); путь загрузки целиком под
  `catch_unwind` в `start_load_thread` → `JobState::Failed(load_panic_message)`
  → экран Failed с Retry; бут/env падает на старте с осмысленным текстом.
- **Смежные семейства** (паники без ключевых слов): `Duration::from_secs_f32`
  (панкует на NaN/отрицательном/бесконечности) — 26 сайтов, все безопасны;
  локи Mutex/RwLock — отравление, продакшн толерантен.
- **Границы** (не брались, сознательно): индексирование срезов `[i]`,
  целочисленный делитель ноль, `commands.entity` на деспавнутой цели —
  классы с сотнями сайтов, соседние углы №26/№32/№58 их уже держат.

## Находки и фиксы

- **Фиксов нет — это вердикт, не пропуск**: дисциплина паник в кодовой базе
  единообразна (паника на сломанном инварианте лучше молчаливой порчи,
  у каждого expect сообщение-инвариант), все голые unwrap несут локальную
  гарантию, путь загрузки застрахован catch_unwind + толерантным Retry.
- Метод-находка: ловушка стриппера cfg(test)-на-айтеме (детали в заголовке
  и в уроках) — стоит помнить любому будущему статическому свипу по src.
