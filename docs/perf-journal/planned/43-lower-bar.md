Приоритет: **1** — заезд 45. Планка ~100 м/с закрыта целиком (52): сим 207
(структурный кап rate 960 тиков/с × 0.215 мс/тик, 50), GAP 134 (сантехника

Кандидаты с числами (записи 50/51):

1. **Снимок 44 м/с** (`snapshot_previous_sim_positions`, 0.046 мс/тик) —
   крупнейший *названный* app-кусок: скан `Changed<SimPosition>` по всем
   20k пешек **каждый тик** (фильтр Changed итерирует архетипы запроса
   потыково — цена от полного населения, не от числа сдвинувшихся).

   совпадает с выборкой Changed прошлого тика, и каждый писатель уже

   стык (51), счётчики команд показали ~3 командных события на тик без

   param/executor-накладные исполнителя, или неизмеренные системы
   (separation **не** входит в `sim/*_ms`; devour, спавнер-внутренности) —
   неизвестно. Инструмент атрибуции: `macOS sample` (урок 51 — первым),

## Единица измерения

**мс CPU на секунду стены** — планка рантайма (запись 50). Тиковые
куски: мс/тик × 960 тиков/с (actual 15 × 64 Гц на 60 Гц дисплее);
кадровые × fps. Медианы: живая пара 3+3 вперемешку, свежие процессы,
холодный первый прогон в медиану не берётся, 32 с между прогонами,
тёплые перезагрузки Парижа (снапшот-хит, парсов 0). `sample` — 4 с по
живому прогретому процессу, 2–3 прогона.

## Не рычаги (стены, не пытаться)

- **Rate тика** — 960/с = 60 fps × 16 тиков (actual 15 — кламп
  `MAX_FRAME_DELTA`, запись 50); `MAX_FRAME_DELTA` — предохранитель
  «заморозка ≠ лавина», 30× — продуктовый кап. Тик-рейт не резать.
- **Сведение сетов / перенос sync-пойнтов** — меняет моменты применения
  команд = порядок потока решений (детерминизм); без симптома не трогать.
- **post / render-CPU** — движковые (51/52), масштабируют счётом
  извлекаемых сущностей; продуктовые рычаги (LOD/мердж пешек) — решения
  автора, вне заезда.
- **Tick-пробы разреза** (6 систем в `FixedUpdate`, коммитнутый код) —
  нужны разрезу тик-спайков (03); оценка ~6–12 м/с, гейтить — усложнить
  спайк-инструмент ради шума. Не трогать.
- **Тик-конвейер** (`species-behavior`, `determinism`): бросок демона —
  прямой сдвиг `SimPosition` в behavior-срезе; его интерполяционная
  семантика не меняться (дельта рендера ≤ смещение одного тика).
- **Запреты чужих направлений**: `planned/07` (кровь — закрыта);
  `map/footprint.rs` и `navigation/navmesh/{gates,reach,fill}.rs` (26);
  vendor-патчи полимеша (29); `map/inspect.rs`, `map/osm/download.rs`,
  `src/loading.rs`, `map/osm/model.rs`, `map/osm/model/trees.rs` (30).

## Инварианты (правка обязана их держать)

- **Поток решений бит-в-бит**: `PreviousSimPosition` вне потока решений
  (читают только интерполяция и `move`) — бросков/убийств/заявок не
  касается; никаких новых `WanderIndex::next`; реплеи-тесты зелёные.
- **Интерполяция**: prev = значение на начало тика для одиночных
  писателей — бит-в-бит; multi-writer за тик (ходьба+толчок) — дельта
  ≤ смещение одного тика (суб-пиксель); остановившиеся не протухают
  (collapse при остановке — prev = конечная позиция, без джиттера).
- **Выходы бит-в-бит**: `road meshing:`, `osm map:`, `entities:` —
  фикс их не двигает.
- **Tелеметрия**: `killed + escaped + alive == HUMAN_COUNT` (на паузе).
- **Ноль эффекта без env** для инструментации (TEMP-патч не коммитится,
  скобки под `QWE_PERF_CUT_PROBES`).

3. Если стеки неоднозначны — TEMP-скобка separation (PROBES-гейт) и/или

**Фаза Б — фикс: fold снимка в писателей** (кандидат по умолчанию;
если фаза А покажет съёмный кусок крупнее — цель переносится, fold
остаётся вторым):

- Писатели `SimPosition` и их правила prev (порядок в тике: behavior →
  move → separation):
  - `move_moving_entities` — в ветке записи при сдвиге:
    `previous.0 =` до-сдвига (первый писатель для не-бросающихся);
    при остановке (`Arrived`/`Halted` → `to_idle`): collapse
    (`previous.0 =` конечная позиция) — стоящие не протухают;
  - separation push — `previous.0 =` до-толчка **только** если пешка не
    ходила этот тик (гейт `Has<MovableStateMovingTag>`: у ходившей prev
    уже поставлен move; пришедшая-и-остановленная командой этого тика —
    суб-пиксельная дельта, допустимо);
  - бросок (`chase`, behavior-срез, до move): `previous.0 =` до-броска —
    бросающий после `to_idle` не ходит этим тиком, он единственный
    писатель (separation его исключает);
  - `rescue_from_impassable` — уже ставит prev (не трогать);
  - спавн — бандл несёт оба компонента (не трогать).
- Удалить `snapshot_previous_sim_positions` (+регистрацию в
  `movement/mod.rs`, +`SIM_SNAPSHOT_MS`: `diagnostics.rs` (константа,
  регистрация), таблица `"snap"` в `sim_time.rs`).
- Семантика: одиночный писатель — prev бит-в-бит как у снимка; ходьба+
  толчок — дельта ≤ один тик (суб-пиксель); остановка — collapse ровнее
  снимка (снимок схлопывал через тик).
- Тесты-пины (`movement/tests.rs`): ходьба — prev = до-сдвига; толчок
  стоящего — prev = до-толчка; остановка — prev == текущая; бросок —
  prev = до-броска (в `demon/behavior.rs` тестах).

**Темп-патч** (не коммитить, `/tmp/perf45-temp.patch`): копия
