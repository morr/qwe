# Запланировано 04 — ускорение парса (очередь после 01–03)

Приоритет: **4**. Два независимых пункта; брать по одному.

## 4a. Ground pockets — rayon

- Запись 10: «18282 ground pockets by the roads sown with grass in 2.785 с» —
  крупнейший шаг парса Парижа (6.5 с всего; дальше входы 0.93 с, деревья 0.71 с).
- Идея: карманы независимы — rayon по карманам (или по клеткам карты).
- Проверить прежде всего: нет ли у прохода скрытой зависимости порядка
  (детерминизм раскладки травы — сид от точки, порядок обхода меняет
  только порядок независимых записей; сверить с `map/seed.rs`).

## 4b. Бинарный снапшот MapData

- Парс 160 МБ JSON каждый запуск: 6.5 с на Париже. Сериализованный бинарный
  снапшот `MapData` (bincode/postcard) рядом с JSON-кешем → загрузка <1 с.
- Инвалидация: `QUERY_VERSION` + `ParseKnobs` (lane_width, navtile, raw) в имени
  файла, как у JSON-кеша; пишет после успешного парса, битый снапшот
  само-лечится (удаляется, парс заново) — как JSON.
- Большой заезд: `MapData` широкий (сериализация многих типов), плюс размер
  файла (сотни МБ?). Делать, только если после 02 тёплый старт всё ещё
  доминируется парсом.

## Замечание

После 02 (мешинг в поток + параллелизм) тёплый старт Парижа ~15–16 с: парс
6.5 с станет крупнейшей последовательной частью — тогда 4a/4b окупаются.
