## Что влито (ветка pop48, 6 коммитов, ff на b5a25bdf)

- **Ядро запекания** (№48): `silhouette/bake.rs` — `BakeQueue` (ставится тем
  же проходом, что снимает spread крови), пекарь ≤256 квадов/кадр,
  `CorpseField` — сетка 500 м, `rebuild_dirty_chunks` ≤4 чанков/кадр
  (`Assets::insert` поверх живого Handle — `Modified` эмитится, id не
  меняется), деспавн ≤768/тик в хвосте `HumanBehavior`; `point.wesl` —
  разворот квада на GPU из «центр + полуразмер + пол», юниформ зума.
- **Гейт регистрации** (№49): `Material2dPlugin` везёт системы, которым
  нужен `AssetServer`, — на голых App (стендовые тесты, реплей на
  MinimalPlugins) паника; регистрация по `is_plugin_added::<AssetPlugin>()`.
  Нет рендера → материал не живёт → пекарь стоит, трупы остаются
  сущностями, реплей-пины целы.
- **Повороты** (№49): тело лежит с `pose.heading`, пятна с `heading + spin`;
  углы вершин поворачиваются на CPU при сборке меша, uv — явный
  `Float32x2` неповернутого угла (зеркало живёт в uv, намотка CCW
  константа) — до шейдера повороты не доезжают.
- **Отсечение** (№49): геометрия едут кастомным атрибутом мимо
  `ATTRIBUTE_POSITION` → AABB единичный у origin → фрустум отсекал весь
  чанк вне угла карты; `NoFrustumCulling` на чанк (подробно — журнал 70).

## Негативы, остатки и уроки (следующим звеньям)

- **«Смерть» звена проверять `get_session`, не верить отчёту предка**: №48
  числилась умершей на квоте, а была жива и дорабатывала ядро — №49
  стартовал с «№48 пропущен», пока №48 ещё заканчивала; коллизия
  разрулена перепиской (№48 встала в сторону, финиш за №49).
- 30-мин прогон с волнами (критерий плана) не гнан — полка подтверждена
  ~5 сим-минутами шторма; эндшпиль-кадр «не дороже 12k-трупного» снять на
  нём же. Ф4 этого не требует.
- Нет-импорт закоммичен и исправлен следом (7e8b376c → b5a25bdf): после
  компакции собирать ДО коммита, не после.
- Линк-фейл тестов после убитой на полпути сборки (сотни undefined
  `.llvm`-символов): два прогона prune-target-objects не помогли, лечится
  `cargo clean -p qwe` + чистая пересборка (~2 мин).
- worktree perf43 зачищен (директива владельца в старте №49; worktree и
  ветка отсутствовали ещё до звена) — пин №44 «СОХРАНЁН» и TEMP-зонд №43
  утеряны; разрез «№44б» при необходимости начнёт зонд заново.
- Зум камеры через BRP не прилипает (`PanCamera` переписывает) — только
  `MouseWheel` с hover-якорем; свежий труп на паузе не печётся (spread
  заморожен — не доходит до очереди).

## Вердикт по перфу

Тик не задет: 3.25–3.28 против 3.2–3.7 Ф2 (возраст мира разный — читать
только как «не дороже»). Рендер-сторона разгружается: трупы покидают
спрайт-конвейер (resize, `FreshSilhouettes`, z-сортировка) ради ≤1 меша на
клетку. Добавленная сим-работа вся под бюджетами (256 квадов/кадр,
4 чанков/кадр, 768 деспавнов/тик). Спайки кадра 30–40 мс ~1/с —
регулятор на 4-тиковых кадрах (0 новых на паузе), не Ф3.
