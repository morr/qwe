## Негативы, остатки и уроки (следующим звеньям)

- **CrossDependency инициализации** (журнал 73, урок в код-комментарии
  demon/mod.rs): явные рёбра `.after(pick).before(chase)` на системах,
  стоящих СОСЕДЯМИ внешней цепочки того же кортежа — ребро цепочки ложится
  после всей внутренней тройки, замыкая отношение chase↔его SystemTypeSet.
  Симптом: несколько тестов «FAILED» без запроса + один тест висит в
  app.update навсегда (инициализация расписания не доезжает). Чинить
  структуру, не тесты.
- Четвертование acquisition дало −45 %, не −75 %: декомпозиция «фикс
  ~0.39 мс (claims) + обход» по парам B/N не подтверждается ценой
  HashMap на 1200 целей (~десятки мкс) — вероятнее поисковая плотность
  гуляет с формой шторма; копать с инструментом на сам поиск, не гадать.
- Ф6 критерий «≤0.3 мс/тик»: демон-блок ~0.9 (acquire 0.49 + chase 0.4);
  chase не трогается Ф6 по плану. Дальнейшее — граница дизайна
  (ChaseClaims обязаны быть полными у каждого прохода).
- Коммит компакции 1d842d65 сделал master расходящимся с веткой звена —
  перебейз одной веточной ветки перед ff, файлы не пересекались.

## Что влито

- **`silhouette/far.rs`** (~560 строк) — дальняя пешка (`FarTag`) рисуется
  точкой в меше чанка: решётка 250 м, точечный материал и квадовый формат
  пекаря. Источник правды — сам мир (`SimPosition`/`Attire` при перестройке,
  копий нет, срезный тик не пишет). Перестройка — бюджет 12 000 квадов/кадр:
  сначала грязные чанки, остаток — кольцу по отсортированным ключам с
  пропуском свежеперестроенных; членство — единственный обсервер
  `Insert<FarTag>`, обратного нет (перестройка выкидывает уехавших и
  не-дальней, опустевший чанк удаляется). Отсечение — честный `Aabb`
  (центры ± 4.5 м) + `NoAutoAabb` — вместо `NoFrustumCulling` трупных.
  `Z_FAR_CROWD` 3.5 в `map/z.rs`; `size_fresh_silhouettes` /
  `resize_silhouettes_on_zoom` получили `Without<FarTag>`.
- **Два живых дефекта, пойманных прогоном и не ловившихся тестами** —
  `WorldStarted` триггерится на входе в `Live`, ПОСЛЕ warmup, за который
  слой уже заселяется: сброс стирал хранилище, 713 сущностей первой волны
  оставались, вторая волна спавнила вторые (×2 на клетку; диагностика одним
  TEMP-eprintln, «cleared, had 713» между двумя волнами по 713 спавнов);
  сброс теперь деспавнит сущности чанков вместе с полем, тест сброса пинит
  и смерть сущностей. `calculate_bounds_2d` (bevy_sprite) перезаписывает
  границы при `AssetChanged<Mesh2d>` из позиций вершин — единичные углы
  у нуля, ловушка трупных чанков: каждая замена меша клампила чанк к ~1.4 м
  у начала карты, слой прятался (ViewVisibility 0). Фикс — `NoAutoAabb`.
