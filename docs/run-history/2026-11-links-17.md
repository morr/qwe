- **Floods шага калиток параллелизованы** (`gates.rs`). Было: flood по
  ограждённой сетке → клон `reachable` → полный проход за seed-ами (оградные
  тайлы, касающиеся достижимого) → flood по bare-сетке. Стало: оба flood
  стартуют от портала и идут параллельно в `thread::scope`. Ключ —
  эквивалентность: достижимое без оград = bare-компонента портала
  (`bare.passable ⊇ passable`, ограждённая компонента лежит в ней целиком,
  а тайл bare-компоненты вне её примыкает через тайл, закрытый только
  оградой — ровно множество скана seed-ов). Скан seed-ов и клон ушли вместе
  с зависимостью между обходами. Вырожденный случай (непроходимый старт —
  снап вернул сырую подсказку) сохранён гардом: оба набора пусты.
