## Найдено и влито (ветка perf29, 1 коммит → ff master; check.sh OK, cargo
## check --lib главного чекаута после ff — OK)

1. **Нечитаемый кеш → Failed без самоизлечения.** Усечённая запись
   (убитый процесс, диск полон) рвёт utf-8 посреди кириллического
   названия улицы — `read_to_string` падает, и провал чтения уезжал в
   `Failed` мимо самоизлечения (оно ловило только провал разбора). Живо
   воспроизведено на master: «Map load failed: cache read: stream did
   not contain valid UTF-8», Retry (brp click 960 561) повторяет отказ
   в точности — файл нетронут, сеть не дёргается, петля вечная. Фикс:
   в `run()` провал чтения лечится тем же путём, что битый json — файл
   удалён, ответ качается заново (одна загрузка, отказа не видно).
2. **Валидный JSON без карты кешился бы навсегда.** Зеркало под
   лимитом/таймаутом отвечает валидным json (пустой `elements`,
   служебный `remark`) — гейт «начинается с `{`» пропускает, разбор
   проходит (парсер содержимое не валидирует: TEMP-проба сцены без улиц
   прошла насквозь, «0 streets, 0 buildings»), и пустой город
   закешировался бы и заснапшотился навсегда: самоизлечение срабатывает
   только на провале разбора. Фикс: `download.rs::validate_answer`
   (дороги не пусты) на границе загрузки — в `run()` для кеша и в
   `download_and_cache` для свежей скачки; гейт на границе, не в
   `parse()`, чтобы сцены фикстур без дорог и окна витрины остались
   годными.
3. **Отравленный снапшот оказался хуже предсказанной Failed-петли —
   молча пустой мир.** Живая проба (TEMP-пример писал валидный снапшот
   roadless-карты с настоящим штампом): «snapshot hit» (заголовок
   валиден), заливка 1.4 мс, 0 калиток, 0 прунинга — мир молча вошёл в
   Live, 19 988 людей бродят по пустоте; отрава липкая: `run()` вернул
   Ok, `snapshot::write` не вызывается — яд обслуживал бы все будущие
   загрузки. Фикс: `snapshot.rs::deserialize_from` считает снапшот карты
   без улиц битым (удалён, разбор с json-кеша).

Живая верификация «после» (fix-бинарь): проба B — отрава отклонена
(«corrupt: decoded map holds no roads»), удалена, реальный json
распарсен, настоящий снапшот перезаписан, мир здоров (14598 зданий,
114 калиток, 15535 пруннутых тайлов, 19957 человек, panics 0). Проба A —

## Негативы с основаниями

- **Атомарная запись кеша (temp+rename) не делалась**: покупает ничего —
  запись идёт только когда кеша нет или он только что удалён (имя несёт
  версию запроса, перезаписи живого файла не бывает), а с фиксами выше
  усечённый файл лечится той же загрузкой без Failed-экрана.
- Снапшот без json-кеша (`json_stamp → None`) не удаляется сразу —
  переживает до смены knobs (подметёт prune) или перекачки (перезапишется
  тем же именем). Один файл на город+knobs, не течёт.
- Cap на размер скачки не ставился: зеркала — константы, не атакуемая
  поверхность.
