# Журнал производительности qwe

Детальная история охоты за performance issues: гипотезы, замеры, фиксы, опровержения.
Краткий индекс — артефакт-журнал: <https://artifacts.spacehubstore.com/a/qwe/qwe-perf-journal>.

## Структура

- `NN-<slug>.md` — записи истории, по одной на запись журнала. Файл каноничен: в нём
  полное описание, в артефакте — одна строка и путь сюда.
- `planned/NN-<slug>.md` — спецификации запланированных доработок. Пишутся до работы,
  рассчитаны на агента, который заезда не видел: цель, доказательства с числами, дизайн,
  шаги, верификация. Взял в работу — работай по файлу, а не по строчке в индексе.

## Правило ведения

Новая запись (замер, фикс, опровержение) — сначала файл `NN-<slug>.md`, затем строка
в артефакте (get_artifact → правка → update_artifact с expectedRev). Запись без файла
не считается опубликованной: артефакт хранит только индекс.

## Итог серии (закрыта записью 57, 2026-11-16)

Все классы затрат получили владельца либо сняты; следующий уровень — продуктовые
решения автора (хвост «Очередь поменьше» в артефакте) или движковые (bevy 0.20).

- **Тёплый старт** — закрыт (49): warmup-шторм, перепись и пины.
- **Холодный старт** — парс (38); снапшот `MapData` снял повторную цену.
- **Рантайм при планке ~100 м/с** — закрыт (50/51/52).
- **Рантайм при планке 50 м/с** — плато-отметка (56): сим ~173 м/с — структурный
  кап 960 тиков/с; GAP ~130 — сантехника стыков (sample-подтверждена); post ~130 —
  extract движка; render 55–84.
- **Джерки** — плато (53): вход, кронные кроссинги, перебатчировка фазы.
- **Архетипные волны** — плато-отметка (57): пространство глобально процессу,
  первый мир ~166 сочетаний, далее 26–32 транзиентов; волна-спайки 2–3 кадра ×
  30–65 мс на вход; оси — конвейерные (off-limits) и движковые (`add_mesh`).
- **GPU** — пуст (55).
- После закрытия серии (58): перекрытие navmesh-префикса с лейнами на скрытом
  бакете заборов — −0.65 с тёплого входа Парижа при дальнем зуме; вид владельца
  (ближний бакет) держит серийный путь.
- После закрытия серии (59): раунды калиток перестают пересканировать сетку —
  шаг калиток тёплого входа Парижа −111 мс (−30 %, 370→259 мс) на виде
  владельца, калитки и прунинг бит-в-бит.
