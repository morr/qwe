## Направление — разрез фаз, фикс крупнейшего куска

Разрез (временные `eprintln`, снятые до коммитов, патч в `/tmp`): фазы
`NodePaint::new` — слияния (чистые merges), фильтр узлов краски
(`painted`/`is_corner`), сетки меток (`marks`/`near_marks`), переходы
(crossings), `PavedIsland` + `nodes_along`, `clusters`, **краска кластеров**
(внутри — по фазам `paint_cluster`, если крупный), хвосты (неиспользованные
переходы, `breaks_across_zebras`, spill, `bridge_short_runs`,
`join_touching`/`without_overlaps`), плюс сам `Junctions::new` для сверки с
записью 40. Сумма сверяется с ≈393.

Фикс — **крупнейший кусок ≥150 мс**, параллель по шаблону `in_parallel`
(`map/parallel.rs`; пробы пар/перепонки/стежки — запись 39, краска узлов
com-лайны — запись 40): чанки + частичный аккумулятор + раскладка в порядке
чанков. Кластеры по построению пространственно разъединены (union-find по
зоне), краска кластера пишет только в свои слои — кандидат на чанки с частичным
`NodePaint`-накопителем и раскладкой append'ом в порядке кластеров (как
`Painter::append_from` записи 40). Выходы обязаны остаться **бит-в-бит**:
счётчики ОБЕИХ строк `road meshing:` (отчёты обеих ступеней сплит-двери) —
контроль.

**Правило выхода** (заезды 29/30): если рычаг в замороженных файлах
(`map/footprint.rs`, `navigation/navmesh/{gates,reach,fill}.rs` — запись 26;
vendor-полимеш — запись 29; `map/inspect.rs`, `map/osm/download.rs`,
`src/loading.rs`, `map/osm/model.rs`, `map/osm/model/trees.rs` — запись 30;
кровь — planned/07), или крупнейший кусок <150 мс, или цена меньше планки —
следующая по рейтингу фаза записи 40 (лента ≈274 — серийный проход в порядке
заливки; gores ≈273 / mouths ≈265 — union-куски записей 27/34;
corners_steps 420 / finish_split 0.8–1.0 / verges_prep 294–332 — стены
уже-параллельных кусков: их собственные фазы), и это фиксируется в этой спеке
и записи 41.

## Ожидание и риски

- Цель: разрез закрывает `NodePaint::new` именованными фазами со свежим
  рейтингом; фикс снимает ≥150 мс серийной работы скелета (`road meshing:`,
  «перед лентами», whole set медианой живой пары). Обещать больше без разреза
  нельзя.
- Эквивалентность: счётчики обеих строк `road meshing:` (включая vertices)
  бит-в-бит во всех прогонах обеих сторон; `NodePaint` не пишет в `MapData` —
  `SNAPSHOT_VERSION` не трогается.
- Риски: `paint_cluster` мутирует `breaks`/`asphalt`/`solid`/`quiet`/`pockets`/
  `throats`/`zebras`/`zebra_roads`/`stop_lines`/`spills` по дорогам кластера и
  общий `crossings` (`used`) — раскладка обязана сохранять порядок кусков на
  каждой дороге; `crossings` размечаются кластером зоны — кластеры разъединены,
  но проверять дизъюнктность записей; сетки `marks`/`near_marks`/`nodes_along`
  и замыкания `sidewalk`/`partners`/`on_ring` — только чтение (Sync);
  `nodes_along` строится по порядку junctions — порядок сохранять.
- Витрины и бенчи (`build_roads_from`, `map_meshing`) идут через ту же
  сборку — их отчёты остаются контролем.
