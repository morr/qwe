## Что исправлено: полимеш-лейн (`1f385c73`)

**Было.** `build_polymesh` платил за четыре цельногородских прохода i_overlay
одним `overlay` на 75–148 тыс. контуров (разрез бенча, Париж):

| фаза | мс |
|---|---|
| **Difference** (blockers − carves, 75430 → 14814) | **766** |
| **Intersect** с прямоугольником карты (14826 фигур) | **377** |
| fence gaps (7080 оград − 16094 проёмов) | **259** |
| union надутых колец (14774 → 12678) | **195** |
| curb (CurbCoverage) + сбор blockers/carves | 445 |
| inflate | 8.7 |
| chunk + bake + stitch | ~407 |
| **итого бенч** | **2225–2248** |

**Правка** — разложение записи 25 (клетки 256 м, `in_parallel`) на все четыре:
`shadow::difference_of` для fence gaps, новый `shadow::difference_of_shapes`
для главной разности (фигуры едут в клетку **целиком** — дыра обязана ехать со
своим наружным кольцом: одинокая дыра в чужой клетке под NonZero заполнена, то
есть остров Сены становился препятствием; первый вариант на плоских контурах
давал 13 промахов против 9 у базы на 500 запросах бенча), точечная отсечка
прямоугольником (пересечение с прямоугольником дистрибутивно по объединению —
фигура целиком внутри проходит без оверлея), `shadow::union_of` для надутых
колец (вход без дыр — надутые наружные, клетка их не разлучает).

**Замеры.** Бенч (Париж, соло): 2248 → 1026 мс (−54 %); полигоны 143849 →
143943 (+94, класс перестановки). Живая пара ситисвитчами одного вечера:
полимеш 3.1/3.1/3.3 → **1.7/1.6/1.4** (−50 %); whole set 3.7/3.6/3.7 →
3.6/3.6/3.5 (стена — roads, не двинулась, как и у заборов в записи 25);
warmup 1.89/1.82/1.95 → 1.86/1.89/1.87 — без изменений. Эквивалентность
поиска: 500 блужданий бенча — found/missed и список промахов бит-в-бит с
базой; аудит стартовой области Парижа — те же вердикты и те же числа вейпоев
(32/31/18) бит-в-бит; портал на меше в обоих. `tools/check.sh` — зелёный
(включая ярды реплеев и `a_restart_replays_the_run`).

## Остаток: список проблем по убыванию цены

1. **Дороги, ступень обочин 0 — стена whole set** (4.5–4.9 живьём, 3.5–3.7 в
   спокойной машине; бенч 2558, из них запись 24 атрибутировала ~800).
   Спланировано: **`planned/16`, заезд 17** — разрез остатка бенча
   (~2.3 с: нарисованная сеть, узлы, краска, мосты, earcut ~6 млн вершин) и
   разрыв живой/бенч пофазно. Не дублировать.
2. **Окно входа в мир (warmup-строка ~1.9–2.0)** — сегменты записи 23
   подтвердились на сегодняшнем дереве (`QWE_PERF_PHASE_SPIKES=150`, живой
   Париж): trans (флеш спавна) 663–687, update (inspect-индекс) 341–352,
   post (сканы материалов) 190–196, inter (extract) 548–561. Единственный
   проектный рычаг из записи 23 — **inspect-индекс в лоад-поток** (~0.3 с):
   требует DrawnPieces из дорожного лейна (osm-map, отдельная работа).
   Остальное — апстрим (extract, `AssetChangeCheck`) или за инвариантами
   (warmup-каунт, флеш крон).
3. **Polymesh chunk+bake+stitch — 407 мс** (после фикса — половина лейна):
   chunk 156 (уже по потокам), bake 118 (серийный `Mesh::bake` — это
   `Layer::bake` по слоям, слои независимы — кандидат в `in_parallel`),
   stitch 133 (серийный, глобальный граф). Мелкий пункт.
4. **Сбор blockers — серийные `ribbon_outline`** по 7080 оградам, 408
   мостам, стенам и водотокам (~150 мс после выноса fence-gap разности).
   Шаблон «вклад по дорогам в порядке входа» записи 24. Мелкий пункт.
5. **Плотная клетка тайловых оверлеев** — общий пунктир записи 25
   (адаптивное дробление): касается и новых клеток полимеша, если полимеш
   снова окажется у стены.
6. **Свежий процесс дороже ситисвитча** (первый прогон процесса: лейны
   целиком на 30–40 % медленнее первых ситисвитчей того же процесса,
   компиляция пайплайнов/память) — не разбиралось; ситисвитч-пары
   сравнимы, свежие процессы — с оговоркой.
