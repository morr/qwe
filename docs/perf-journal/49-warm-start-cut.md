**Фикс — два коммита:**

1. **Уровни отмели по ядрам**: 12 outline-проходов (`levels[0].outline`
   с глубиной `level × SHOAL_STEP`) независимы — каждый считается из
   полной воды, а не из предыдущего уровня, и раньше шли по одному.
   `in_parallel(&depths, …)`, результаты в порядке уровней, обрезка по
   первому пустому — тот же ранний выход, что у серийного цикла, так что
   список уровней совпадает с ним бит-в-бит (те же вызовы `outline`,
   порядок восстановлен; монотонность эрозии не нужна — пустой уровень
   глубже необязательно пуст, но обрезка останавливает список там же,
   где останавливался `break`).
2. **Полосы уровней по ядрам**: уровень читает только свой набор и
   вложенный в него; частичный `MeshBuilder::with_surface_coords()` на
   уровень + `append` в порядке уровней — та же последовательность
   вершин, что у серийного прохода (шаблон развёрток теней
   `shadow.rs::push_union`, запись 31).

**Метод** (новое к методу записей 36–48):

- **ранний выход по пустому уровню сохраняется в параллели обрезкой по
  первому пустому**: списку уровней не нужна монотонность эрозии —
  обрезка останавливает список там же, где серийный `break`, что бы ни
  делала дискретизация i_overlay с глубинами уровней; цена — вычисленные
  зря уровни после первого пустого (на Париже пустых нет — Сена держит
  все 12);
- **`brp quit` — не гарантия смерти процесса**: за заезд два инцидента,
  когда `AppExit::Success sent` уходил, а процесс продолжал держать
  порт, — старт следующего приложения паниковал на занятом BRP_PORT
  (урок 41). После каждого гашения — `$b procs` и/или
  `pgrep -f target/debug/qwe`; свой выживший — `kill <pid>`.
- whole set = max лайн + ~0.2 — подтверждено на целиком тёплом старте:
  одноуровневый пул лайн ничего не прячет, GAP-проверка «суммы фаз против
  wall» закрыла окно у small/fences (0.2–0.5) и buildings (~19 —
  сантехника слоёв и отчёта).
