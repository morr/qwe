## Чистые зоны свипа (негативы с основаниями)

- **MapData**: писатель в Update один (`recompose_row_trees`, меняет только
  `map.trees`), все читатели — `Res` непересекающихся срезов; единственная
  видимая зависимость — `sync_panel_counts` на кадр отстаёт при смене стиля
  деревьев — benign, не трогать.
- **Клавишные инспектора** (cycle_next/cycle_prev/pin/clear) — ResMut
  одного state при физически взаимоисключающих run_if; оставлены unordered
  осознанно.
- **capture_offscreen** против камер/бакетов/силуэтов — намеренная
  перезброка слоёв под зум выстрела (`WARMUP_FRAMES`), не трогать.
- **Update-косметика/ретюнинг** (`draw_lunge_paths`, `pulse_devouring`,
  `sync_demon_speed`, `sync_human_pace`) — run_if-гейты, пары с конвейером —
  1-кадровые benign; `sync_demon_speed`/`sync_human_pace` пишут скорость при
  смене стиля (Local-compare), не тик-системы.
- **SimSpeed/Time<Virtual>/SimClock/WorldSeed/InspectIndex/Visibility/
  PathfindingRequest-диагностика** — только 1-кадровая свежесть отображений,
  правка не оправдана. PanCamera-пары: drag/zoom/key пишут разные поля.
- **StateTransition (37) / PreUpdate / Last / RunFixedMainLoop** —
  bevy_state-внутренности (generic с `qwe::` в параметрах), exclusive
  `archetype_census` против bevy-Last, camera-controller против entity-дизжойнт
  ридеров — не наши, не трогать.

## Остатки и уроки (следующим звеньям)

- Угол закрыт механически: детект перечисляет всё, рёбра стоят, целевые
  пары ушли (2883 → 2834; остаток наших — разобранный benign). Врезка
  одноразовая (TEMP), при следующем пересмотре порядка ставится заново
  за пять минут (форма — в истории этой секции).
- **Редкий сценарий, не гонка**: `capture_offscreen` временно двигает
  пользовательскую камеру, `track_camera_view` в Save-режиме пишет вид во
  время выстрела — сохранённый вид может запомнить временный зум.
  Триггер: жалоба владельца на saved-вид после offscreen-выстрелов.
- **Урок API**: `.after((a, b, c))` кортежем систем в Bevy 0.20 не
  компилируется (E0277 «is not a system set») — только цепочка
  `.after(a).after(b).after(c)`.
- **Урок фильтра**: generic-параметры (`<qwe::loading::AppState>`) в именах
  bevy-систем ложно матчатся на «наши» — фильтровать пары по началу
  стороны пары, не по подстроке.
- Оптимизационное меню по-прежнему пусто (продуктовые решения владельца:
  вариант-в заборов, vendor northstar; остатки записи 62 ниже шума).
  Следующему звену — свежий угол; взятые — в постоянном разделе.
- worktree perf27 и ветка не помечены «сохранён» — удалить (слиты в master).
- Уроки №16–26 подтвердились; новых cwd-граблей нет (статусы двух чекаутов
  читались порознь).
