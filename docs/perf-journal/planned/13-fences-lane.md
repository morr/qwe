# Запланировано 13 — мешинг-стена тёплого старта: дорожка заборов (Париж)

Приоритет: **1** — после записи 24 стену whole set делят ступень обочин 0
(4.1–4.3 живьём) и дорожка заборов (3.8–4.1 живьём в memory pressure,
3.0–3.2 в спокойной машине, записи 22/24). Заезд 15.

## Проблема

Тёплый старт Парижа (снапшот-хит) — 8.18/8.15/7.93 с (запись 24). Дорожка
заборов в `build_world_meshes` строит только ступень входа
(`fences::entry_layers`, зум из `StyleSnapshot`, строка
`map meshes: fences`); ступени целиком стоят по бенчу `map_meshing`
(Париж) — 0.25 м 0.75 с, 0.50 м 1.08, 1.30 м 2.16, из них стадия shadows
~2.0 с — свип и объединение теней, 93 % сборки шага (запись 17).

Назначенный пунктир записи 19: **вычитание настилов мостов до union**
(`fences::push_shadows`) идёт **одним `Difference` по ~400k контуров**
(Париж: 7080 линий → 10 144 куска; каждое звено и каждый узел дают
выпуклый контур свипа), внутрь тайлов `push_union` оно не попадает.
Тайловый union зданий (запись 19) по этой причине заборы не ускорил.
Пересечение порога зума — фоновая задача записи 17, но в prepare-потоке
дорожка делит ядра со ступенью 0 и остальными лейнами (запись 24) и стоит
половиной стены whole set.

## Направление решения

Первый шаг — **разрез стадии shadows** (офлайн бенч `map_meshing paris`,
временные `eprintln`, снять до коммита): развёртка свипов (генерация
~400k контуров), Difference с настилами, тайловый union `push_union`.
Решение — по разрезу:

1. **Тайловое Difference** (главный кандидат, пунктир записи 19):
   тождество `(A−B)∪(C−B) = (A∪C)−B` раскладывает разность по тем же
   клеткам 256 м, что тайловый union — контуры группируются по клетке
   первой точки, каждая клетка вычитает настилы в своём потоке
   (`in_parallel`, порядок результатов — порядок клеток), слитый выход
   едет во вход `push_union` (union как раньше — тайлами на городском
   входе). Настилов мало (сотни капсул); цена повтора клипа на клетку —
   против одного прохода по 400k. Контуры, пересекающие границу клетки,
   вычитаются целиком в клетке первой точки — тождеству группировка не
   мешает.
2. **Свипы по потокам** (если разрез покажет их долю): контур от куска не
   зависит — `in_parallel` по кускам, вклад в порядке кусков (прецедент
   записи 19: развёртки зданий 247 → 51 мс).

## Инварианты (не трогать)

- **Геометрия — функция входа, не потоков.** Тождество гарантирует то же
  множество; порядок вершин может переехать (класс «перестановка
  вершин», прецеденты тайлового union записей 19/22) — дрейф
  зафиксировать в записи честно.
- **`push_union` не трогается** — общий путь зданий и остального
  («The shadow rules» скилла osm-map); правка живёт в стороне заборов.
- **Фоновый билд ступени и гвард поколения записи 17** — инварианты:
  `mesh_fences` остаётся той же чистой функцией для входа
  (`entry_layers`) и пересечения порога (`queue_fence_rebuild` →
  `apply_fence_rebuild`); правка ускоряет оба пути, семантику подмены и
  отбрасывания устаревшего результата не меняет.
- **Пересборка стилем/солнцем** остаётся одной сборкой `mesh_fences` —
  выигрывает от тех же правок, регресса не давать.
- Ленты заборов и их порядок не трогаются (кандидат — только стадия
  shadows); счётчик вершин ленты — контроль.
- Новых спавн-сайтов не заводить (`DespawnOnExit`, `survived` — 0);
  ярды реплеев и `a_restart_replays_the_run` — зелёные в check.sh.
- Гейты 1.44 с и полимеш — не цель заезда, фокус не размазывать;
  `planned/07` (кровь) — занята разведкой другой сессии, не трогать.

## Верификация

- Бенч `map_meshing`: ступени заборов → целевая цифра по разрезу;
  счётчики отчёта (`lines`/`pieces`) и вершины — бит-в-бит или честно
  зафиксированный дрейф класса перестановки.
- Живой тёплый старт: 2 базы + 2 правочных прогона (stash-пара одного
  дня при memory pressure, запись 24), строки `map meshes: fences` и
  whole set; `osm map:` бит-в-бит.
- Картинка: оффскрин-кадр плотного центра Парижа до/после — тени заборов
  той же формы; вырез тени на настиле моста сохранён.
- `world reload: N scene entities survived` — 0; `panicked`/`ERROR` — 0.
- `tools/check.sh` по изменённым файлам (тесты заборов сидят ниже порога
  тайлов — однопроходный путь остаётся; ярды реплеев зелёные).
