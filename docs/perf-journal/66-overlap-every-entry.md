# Запись 66 — перекрытая загрузка на каждой ступени заборов: сериальный префикс спрятан под стену лейнов — −0.39 с вид владельца, −0.27 с Тула

Статус: фикс звена №34 цепочки (ветка `perf34` → ff master). Правки:
`map/prepare.rs` (гейт снят — `build_overlapped_world` единственная форма
загрузки; лейн заборов переехал во вторую волну), `map/osm/download.rs`
(серийный путь `build_navmesh`/`finish_world` удалён), `map/fences.rs`
(`entry_step_hidden` остался лестнице, `#[cfg(test)]`); док-твины — CONTEXT.md
и скилл world-lifecycle. Пин расширен на видимую ступень: слой заборов
бит-в-бит с серийной стороной. Живая пара — два чекаута одного состояния
машины (мастер главного чекаута против `perf34`), чередование A/B, ~30 с
между прогонами, вид владельца (Париж, zoom 0.4, Astar,
`QWE_PERF_NOAPPNAP=1`+caffeinate); окно «snapshot hit → warmup routed» по
таймстемпам строк лога.

**Было.** Гейт записи 58 (`fences::entry_step_hidden`): на видимой ступени
заборов — серийный префикс (fill → gates → prune перед лейнами), потому что
«лейн заборов дорог сам по себе (2.3–2.8 с Парижа) и его старт не должен
сдвигаться гонкой дорожек за ядра» (урок прогона №12, откат варианта-а в
perf12; вид владельца тогда держал серийный путь — запись 58, «вид владельца
не тронут»). Запись 63 срезала лейн заборов ближнего бакета до ~1.0 с
(2.72 → 1.01 с живьём); стеной whole set стал лейн дорог, и основание гейта
исчезло.

**Дизайн.** Перекрытый путь всегда; лейн заборов — во вторую волну (стартует
присоединением дорожки калиток): он читает проёмы оград через `fence_gaps`
(`merge_gaps(&fence.gates, …)` — калитки первыми, дорожные поверх) и ему
нужен клон с уже открытыми калитками — свой клон клона (`scratch.clone()`,
мегабайты и миллисекунды против стены; move-входы вторая волна держит
раздельными — заимствования локалей замыкания `scope.spawn` не разрешены,
урок той же правки). Первая волна: buildings ∥ roads ∥ small ∥ inspect ∥
навмеш-дорожка (fill → снап → калитки на клоне); вторая: prune ∥ polymesh ∥
fences. Слияние калиток в карту мира после всех дорожек — единственная
мутация клона по-прежнему `fences[..].gates`.
