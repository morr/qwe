## Единица измерения

Не мс/с. Видимость джерека: **мс худшего кадра** и **медиана спайков
класса** за прогон (порог детектора 30 мс; для входа — фазовые стены
`QWE_PERF_PHASE_SPIKES=40`); для кроссингов — медиана спайков на кадр
кроссинга при развёртке колеса. Класс закрыт фиксом, если медиана уходит
под порог видимости (джерк исчезает), иначе плато-отметка: класс назван
стеной/продуктовым с записью-владельцем.

## Инварианты (правка обязана их держать)

- **Тик не трогать**: фикс кроссингов не касается `FixedUpdate`; если
  вдруг коснулся — поток решений бит-в-бит, реплеи `tests/determinism.rs`.
- **Telemetry**: `killed + escaped + alive == HUMAN_COUNT` (на паузе).
- **Выходы бит-в-бит**: счётчики своих строк (`road meshing:`, `osm map:`,
  `entities:`) не двигаются — фикс не меняет парс, геометрию и население.
- **Стриминг крон**: пока кроны досыпаются, видна прежняя дальняя ступень
  (дыр в лесу нет, инвариант c31cfd4b); уменьшение пачки не должно
  ломать показ — `TreeLodShown` переворачивается только на полном наборе.

## Дизайн

Инструментация — TEMP-патч в /tmp, не коммитить: перегонка
`/tmp/perf42-temp.patch` (кадровые стены `frame cut` + `tick cut` +
`cmd cut` + обёртка `take_extract` под `QWE_PERF_CUT=1`; extract-штампы
под `QWE_PERF_CUT_PROBES=1` — урок 51: контрольный прогон без проб) плюс
новое, разрез джерков:

- **счётчик кроссингов**: однострочный `info!` из `update_zoom_bucket`
  при смене индекса — тип лествицы (`std::any::type_name::<T>` коротко),
  старый → новый индекс, зум; по кадрам сопоставляется с `frame spike`
  (та же строка несёт зум) — атрибуция кроссинга виновнику без скобок;
- **стены rebuild-сайтов** (`Instant`-скобки, сумма в секунду): 
  `rebuild_cars`, `rebuild_fences` (в т.ч. swap `apply_fence_rebuild`),
  `mesh_trees`/`spawn_tree_meshes`, `show_tree_lod`, `show_rails`,
  `show_road_steps`, `show_paint` — под `QWE_PERF_CUT=1`;
- **счётчики стрима крон**: `cut_cmd::crown(+n)` / `crown_despawn(+n)` —
  флеш пачки в `cmd cut`;
- **развёртка зума колесом**: `brp hover` + синтетический `MouseWheel`
  (прецедент записи 35: кроссинг — 8 шагов за ~2 с), обе стороны каждого
  порога: вниз 4.5 → 0.05, вверх обратно; чтение `brp cam` до/после.

Прогоны (тёплый Париж, снапшот-хит, парсов 0; порт 15704):
`QWE_PERF_NOAPPNAP=1 QWE_PERF_NOVSYNC=1 QWE_PERF_FRAME_SPIKES=30
QWE_PERF_PHASE_SPIKES=40 caffeinate -i cargo run` фоном, строго из
каталога worktree. Порядок замеров в одном процессе: вход (шторм виден с
старта — phase spikes порог 40), первые ~30 с (census + `cmd cut`),
развёртка зума обе стороны всех порогов (медленная, шаг за шагом), 
телепорт-одиночка (`brp cam` за карту → обратно). Медленная развёртка
отличает «спайк = пачка потока крон» (повтор на каждом шаге ниже 0.2) от
«спайк = сам кроссинг» (один на порог).

Кандидаты рычага (по разрезу, не по столу): пачки стрима крон
(`CROWN_SPAWN_BATCH` 4096 → меньше, `CROWN_DESPAWN_BATCH` 16384 →
меньше) — раскладка флеша по кадрам; rebuild_cars — если стена на
кроссинге подтвердится, стриминг по образцу заборов (запись 17).
