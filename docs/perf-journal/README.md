# Журнал производительности qwe

Детальная история охоты за performance issues: гипотезы, замеры, фиксы, опровержения.
Краткий индекс — артефакт-журнал: <https://artifacts.spacehubstore.com/a/qwe/qwe-perf-journal>.

## Структура

- `NN-<slug>.md` — записи истории, по одной на запись журнала. Файл каноничен: в нём
  полное описание, в артефакте — одна строка и путь сюда.
- `planned/NN-<slug>.md` — спецификации запланированных доработок. Пишутся до работы,
  рассчитаны на агента, который заезда не видел: цель, доказательства с числами, дизайн,
  шаги, верификация. Взял в работу — работай по файлу, а не по строчке в индексе.

## Правило ведения

Новая запись (замер, фикс, опровержение) — сначала файл `NN-<slug>.md`, затем строка
в артефакте (get_artifact → правка → update_artifact с expectedRev). Запись без файла
не считается опубликованной: артефакт хранит только индекс.

## Итог серии (закрыта записью 57, 2026-11-16)

Все классы затрат получили владельца либо сняты; следующий уровень — продуктовые
решения автора (хвост «Очередь поменьше» в артефакте) или движковые (bevy 0.20).

- **Тёплый старт** — закрыт (49): warmup-шторм, перепись и пины.
- **Холодный старт** — парс (38); снапшот `MapData` снял повторную цену.
- **Рантайм при планке ~100 м/с** — закрыт (50/51/52).
- **Рантайм при планке 50 м/с** — плато-отметка (56): сим ~173 м/с — структурный
  кап 960 тиков/с; GAP ~130 — сантехника стыков (sample-подтверждена); post ~130 —
  extract движка; render 55–84.
- **Джерки** — плато (53): вход, кронные кроссинги, перебатчировка фазы.
- **Архетипные волны** — плато-отметка (57): пространство глобально процессу,
  первый мир ~166 сочетаний, далее 26–32 транзиентов; волна-спайки 2–3 кадра ×
  30–65 мс на вход; оси — конвейерные (off-limits) и движковые (`add_mesh`).
- **GPU** — пуст (55).
- После закрытия серии (58): перекрытие navmesh-префикса с лейнами на скрытом
  бакете заборов — −0.65 с тёплого входа Парижа при дальнем зуме; вид владельца
  (ближний бакет) держит серийный путь.
- После закрытия серии (59): раунды калиток перестают пересканировать сетку —
  шаг калиток тёплого входа Парижа −111 мс (−30 %, 370→259 мс) на виде
  владельца, калитки и прунинг бит-в-бит.
- После закрытия серии (60): floods шага калиток — в два потока — шаг −29 мс
  (−11 %, 262→234 мс) на виде владельца, Тула −19 мс; калитки и прунинг
  бит-в-бит (16 живых загрузок + probe пяти городов).
- После закрытия серии (61): refill раундов калиток — только в боксах свежих
  проёмов — шаг −47 мс (−25 %, 193→146 мс) на виде владельца, Тула −6 мс;
  калитки и прунинг бит-в-бит (24 парижских + 8 тульских живых загрузок,
  probe пяти городов с хешами всей сетки).
- После закрытия серии (62): кеш проёмов оград строится рядом с fill_base —
  fill-шаг тёплого входа Парижа −118 мс (−46 %, 257→140 мс), растеризация
  сетки бит-в-бит (хеши всей сетки probe-ом, счётчики живых загрузок).
- После закрытия серии (63): плотные клетки теней дробятся на квадранты —
  бенч заборов Парижа −57 % (ступень владельца 1.30: −64 %), лейн заборов
  живьём −63 % (2.72→1.01 с); навмеш не тронут (прунинг 772 506, fill),
  полимеш сохраняет прежний union.
- Опровержение (64): плотных клеток в union полимеша нет — худшая клетка
  Парижа 121 контур против порога 512, dense-путь байт-в-байт; цена фазы —
  финальное слияние результатов клеток (226 из 244 мс), и слияние в кварталы
  4×4 его не режет. Кандидат записи 63 закрыт; чанковая сборка полимеша
  0.05–0.7 с по городам, секунды — flat-режим.
- Опровержение (65): RSS-удержание переключений городов разрезано — это
  MADV_FREE'd свободные страницы системного аллокатора (footprint vmmap
  следует за городом: Тула 1.8–1.9G / Париж 2.2–2.3G; GPU-память освобождается
  бит-в-бит; живая куча плоская после разминки; stale-ресурсов нет). Явный
  malloc_zone_pressure_relief на шве загрузки — но-оп на macOS 26. Править
  нечего; «+50–75 МБ» — артефакт учёта ps RSS.
- После закрытия серии (66): перекрытая загрузка — на каждой ступени заборов,
  сериальный префикс спрятан под стену лейнов (гейт записи 58 потерял
  основание — запись 63 срезала лейн заборов до ~1.0 с, стеной стал лейн
  дорог; лейн заборов уехал во вторую волну — он читает калитки).
  Окно тёплого входа Парижа на виде владельца −0.39 с (4.28 → 3.89), Тула
  −0.27 с (1.14 → 0.87); калитки и прунинг бит-в-бит, слой заборов пина
  бит-в-бит на видимой ступени. Серийный путь удалён.
- После закрытия серии (67): финальное слияние теневого union — кластерами
  пересекающихся фигур вместо однопроходного прохода по всем результатам
  клеток (вёдра — отброшенный кандидат, вышли дороже). buildings shadows
  578–611 → 394–431 мс бенчем, слияние оград 73 → 4.1 мс; живьём buildings
  2.5–2.7 → 2.0, fences 0.91–0.93 → 0.76; окно входа не двигается — стена
  соединения лейнов осталась на лейне дорог. Полимеш не тронут (вход CDT).
- Разрез (68): дороги после 63/66/67 разрезаны по фазам целиком —
  крупнейший CPU лейна: находка лоскутов финалов ступеней (~6.5 CPU-s
  из 23.5 окна, по 341 wall × 2 ступени); клип-фильтр (габаритный и
  через опорные прямые) подтверждает запись 34 — i_overlay режет кольцо
  в точках касания, предфильтр меняет куски; подъём керб-расчёта (calc
  103/lay 24 на ступень) — та же «отдельная работа» записи 28, стену не
  двигает. Стена лейна несжимаема на текущих правилах.
- Фаза 2 ×10 (69): камерный LOD людей на 200k — очередь диспетчера
  197 698 → 0–10 заявок (критерий фазы), 99.6% пешек в дальнем ярусе,
  тик 4.26–4.31 → 3.2–3.7 мс. Три живых итерации (heartbeat-сердцебиение

  цели) сняли far_ms 4.5 → 1.6–1.8; sync-пойнты цепочки поведения — ещё

  ≈ 1.0–1.5 мс против 15×-бюджета 0.31 — разрез следующему звену.
- Фаза 3 ×10 (70): запекание трупов — свежие спрайты переписываются квадами
  в чанковые меши (клетка 500 м): killed 5 117 / baked 5 053 на срезе
  шторма, свежих ≤64, entities стоят на полке (214–217k при 200k населения),
  тик 3.25–3.28 мс — не дороже записи 69. Ловушка отсечения: кастомный
  вершинный лэйаут везёт геометрию мимо POSITION — AABB выходит единичным

- Фаза 4 ×10 (71): демон-орды — волны поверх фона из чистого потока номера
