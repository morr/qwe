# Запись 25 — дорожка заборов: вычитание настилов тайлами — бенч заборов −39 %, лейн живьём −19 %

Статус: фикс заезда 15 (`planned/13-fences-lane.md`) · офлайн-бенч
(`map_meshing paris`) 3 базы и 3 правочных прогона в одном состоянии машины,
живая stash-пара одного вечера (снапшот-хиты, под `caffeinate -i`,
`QWE_PERF_NOAPPNAP=1`/`NOVSYNC`), разрез двумя раундами — временные
`eprintln`, сняты до коммита.

**Было.** Стену whole set (`build_world_meshes`) после записи 24 делили
ступень обочин 0 (4.1–4.3 живьём) и дорожка заборов (3.8–4.1 живьём в
memory pressure, 3.0–3.2 в спокойной машине). Бенч заборов (Париж,
дефолтное солнце): ступени 0.25/0.50/1.30 — 864/1190/2389 мс, стадия
shadows ~2.2 с. Назначенный пунктир записи 19: вычитание настилов мостов
до union идёт одним `Difference` по всем свипам города и внутрь тайлов
`push_union` не попадает.

**Атрибуция.** Разрез стадии shadows `push_shadows` (временные
`eprintln`, бенч, Париж):

| фаза | мс |
|---|---|
| развёртка свипов (48 220–48 229 контуров) | 4.8–5.2 |
| **`Difference` с настилами (1319 капсул)** | **590 / 947 / 2116** — по ступеням 0.25/0.50/1.30 |
| `push_union` (union + кайма) | 88–92 |

Difference — вся стена стадии: одиночный проход по 48k контуров стоит
дороже самого объединения, и тайлы `push_union` до него не дотягиваются.

**Правка — одна, но с находкой посередине.** `shadow::difference_of`
(рядом с `union_of`, `push_union` не тронут): тождество
`(A−B)∪(C−B) = (A∪C)−B` раскладывает разность по тем же клеткам 256 м —
клетка вычитает только капсулы, чья рамка задевает рамку её свипов
(разность с непересекающейся капсулой тождественна; рамки заведомо шире
геометрии, ложный «задел» запускает лишний оверлей, а не портит
результат), `in_parallel` по клеткам, слитый выход — во вход
`push_union` как раньше. Малый вход (тесты, витрины) — прежний
однопроходный путь.

Первая форма пропускала контуры клеток без настилов **как есть** — и
выигрыш съедался: разность падала до 80/116/235 мс, но налегания свипов,
которые раньше снимал один большой `Difference` (выход 6.7k контуров),
переехали в union (вход ~44k) — стадия осталась 1588 мс. Клетка без
задетых капсул обязана **объединять** свои свипы (`simplify_shape`), как
клетка `union_of`: тогда и разность, и слияние идут в одном параллельном
проходе.

**Цена и отвергнутое:**

- **Живой выигрыш лейна (−19 %) меньше бенчевого (−40 %)** — потоки клеток
  делят ядра с соседними лейнами prepare-потока (тот же эффект записи 24),
  а whole set не двинулся вовсе: стена — roads step 0, и заборы от неё уже
  ушли (1.0–1.3 с против 4.5–4.9). Якорь правки — бенч: он же меряет
  ступень 1.30, то есть цену пересечения порога зума (фоновая сборка
  записи 17), которую живой вход на этом сохранённом виде не трогает.
- **Плотная клетка — остаток.** Сверло по клеткам: CPU-сумма клеток
  591/802/1733 мс на 670 клеток, но wall — **одна клетка частного сектора
  №280: 3656 свипов, union 249/427/1210 мс по ступеням** (следующая — №246:
  2053 + разность, 77/118/221; остальные < 15 мс). Параллелизм клеток её
  не режет; цена union сверхлинейна (2053 → 77 мс, 3656 → 249–1210), так
  что заработало бы адаптивное дробление (квадранты с внутренним
  слиянием). Стену whole set не двигает — оставлено как пунктир.
- **TILE 128 для разности** — не пробовалось: перекос переехал бы в
  финальный union (`push_union` группирует выходы по клеткам 256 м и
  собрал бы неслияные выходы подтайлов одной плотной клетки), а тайл
  общего union менять нельзя — здания сидят на нём, и запись 19 уже
  замеряла 128 им в минус.

**Метод.**

- Прогон: `BRP_PORT=15703 QWE_PERF_NOAPPNAP=1 QWE_PERF_NOVSYNC=1
  QWE_PERF_FRAME_SPIKES=30 caffeinate -i cargo run`, фоном; тёплый старт —
  по таймстампам строк лога (снапшот-хит → `warmup:`), лейны — строки
  `map meshes:`, ступень входа — строка отчёта `fences: … at X m`.
  Перезагрузка города — `brp res set City . '"Paris"'`.
- Разрез — два раунда временных `eprintln`: стадии `push_shadows`
  (развёртка/разность/union), затем по-клеточный проход `difference_of`
  (wall против CPU-суммы, топ клеток с размерами) — именно он отделил
  «плотная клетка — доминанта» от «мало ядер»; сняты до коммита.
- Входная ступень зависит от сохранённого вида камеры и между прогонами
  дня меняется (утром 1.30 м, вечером 0.25 м — вид перезаписал другой
  живой процесс): ступень каждой пары сверять по строке отчёта.
- Картинка без скриншот-пар: счётчик вершин отчёта бит-в-бит не
  сохраняется на тайловых путях (класс перестановки), поэтому кадр +
  разностная метрика (`magick … -compose difference`), AE на 16-битных
  png в этом списке врёт — брать mean разности.
