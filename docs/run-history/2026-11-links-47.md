## Негативы, остатки и уроки (следующим звеньям)

- **Три живые дыры LOD, каждая стоила перезапуска**: (1) назначатель спал на
  стоячей камере — первый проход попал до расселения, FarTag 0, очередь 198k
  → heartbeat раз в 4 кадра (demote-половина без движения камеры); (2) onset
  опросом каждой мирной пешки среза = 25k×O(1)/тик = far_ms 4.5 → инверсия
  (демоны × соседи, зеркально ближнему panic); (3) холостой переброс цели
  (бросок + луч) каждым срезом у стоящих в «карманах» дворов → остылка
  0.5–1 с при неудачной цели.
- **rest ≈ 1.0–1.5 мс против 15×-бюджета 0.31 — главный разрез после Ф3.**
  Кандидаты: применение команд to_moving/to_idle на каждом выборе цели
  (archetype-волны), диспетчерский скан очереди, pump, sync-пойнты главной
  цепочки (panic → flee → escape → rise_souls). Метод — TEMP-врезка Instant,
  образец — запись 68.
- **Разброс тика между запусками ±0.4 мс** (шум машины + возраст мира; far
  сам растёт 1.66 → 1.8+ с ходом шторма): до/после чередовать в одном
  запуске или честно писать диапазон — «одно число» здесь всегда враньё.
- **bevy 0.20: `ConflictingSystems::to_string` паникует** (SystemKey-фантом)
  после `initialize`, если конфликты ненулевые — тест-пин «ни одной
  неупорядоченной пары» упал паникой, не ассертом. Лечится полным порядком
  (`chain_ignore_deferred`, `.after`), не фильтрацией списка; список пар
  разбирать по сырым ключам до имени.
- **Восемь срез-копий — Query на 15 полей**: потолок кортежа; следующий
  срезный признак потребует либо `Has<>`-свертки, либо вывода поля в
  отдельную систему.
