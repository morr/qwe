# Запись 7 — Монотик: два слоя — App Nap и честные вспышки скана change-ticks

Статус: разгадано наполовину. Файлы: `.claude/live-app-project.md` · caffeinate (3c6e112a).

**Слой 1 — App Nap.** Мир на 64 людях без демонов ловил «монотики»
20–90 мс при подсистемах <0.01 мс: процесс из агентского шелла наследует фоновый QoS
(`ps -M`: класс `4T` на всех потоках), и macOS троттлит его.
Под `caffeinate -i` — ноль спайков; тик 64 человек — стабильные 0.23 мс,
20k спокойных — 0.93 мс. `taskpolicy` нужного класса не знает. Обёртка
задокументирована в live-app-project.md; **все прошлые замеры тиков из
агентских сессий, сделанные без caffeinate, недостоверны** — включая часть
«тик-вспышек» записей 3–5.

**Слой 2 — честные вспышки.** Под caffeinate монотики остались:
23–91 мс за 1–2 тика пачками, 20k стоящих, ноль убийств, pathfinding-пул пуст (спайк
358 мс при 0 in flight). probe3 (откатан) поймал виновника в моменте:
`snapshot_previous_sim_positions` исполнялся 20–25 мс на **217
строках** — тот же скан обычно стоит 0.14 мс, вспышка = замедление ×100.
Счётчик архетипов в строке спайка — константные 1182 на 20k населения: комбинаторика
тегов состояний размазала пешки, и `Changed<SimPosition>` ходит по
всем архетипам каждый прогон. След охоты: intermittent ×100 на скане по 1182
архетипам — периодическая ревалидация кешей запросов/тиков, ловить следующим
заходом. Структурная цена этого скана — ~31 нс/пешку на каждый тик.

**Честная таблица тика (caffeinate, Tula):** 64 человека 0.23 мс
(фиксированная цена расписания), 20k спокойных 0.93 мс (≈35 нс/пешку), шторм — 2–5 мс.
Регулятор на спокойном 20k-мире честно держит requested 5×.
