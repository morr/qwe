**Правки — три** (мелкими коммитами, каждый с бенчем):

1. **bake по слоям** (`7b468b9f`): QWE-патч vendor — bake как пара
   «посчитать/применить»: `Layer::compute_bake`/`apply_bake` (чистые
   половины `bake_polygon_finder`/`bake_islands_detection`), тип
   `BakedLayer`, `BoundedPolygon` наружу (+`Copy` — pub-тип без него ловит
   `missing_copy_implementations`). Слои независимы до сшивки, bake слоя —
   только чтение его вершин и полигонов: `in_parallel` по слоям, применить
   серийно — порядок слоёв и результат те же. Бенч 1022 → 942.
2. **components по слоям** (`dfdd774b`): `components_of` читает только свой
   слой — `in_parallel(&layers, components_of)`, порядок слоёв тот же.
   Бенч 942 → 915.
3. **reorder соседей по вершинам** (`1dd5fe6f`): QWE-патч —
   `compute_neighbor_order`/`compute_vertex_order`/`apply_neighbor_order`
   (чистая половина reorder: вершина от вершины не зависит, вход — только
   чтение слоёв) и `stitch_mark_and_append` (`stitch_internals` без
   reorder), `StitchVertices` наружу. qwe: после метки стежков `in_parallel`
   по вершинам (динамический счётчик балансирует плотный центр против
   пустой окраины), сборка списков по порядку слоёв, применить серийно —
   те же списки соседей, что у серийного reorder. Бенч 915 → 859.

**Цена и отвергнутое:**

- **`fence_gaps` 122 мс** — самый жирный серийный остаток сборки blockers;
  внутренность `FenceGapCache::build` — `map/footprint.rs`, запрещена
  заезду (запись 26). Пунктир: лейн полимеша мог бы переиспользовать кеш
  заливки (она считает те же проёмы раньше в том же лоад-потоке), но кеш
  живёт в стеке заливки и до лейнов не доезжает — протянуть его через
  архитектуру лоад-потока — отдельная работа, не полировка.
- **`ribbon_outline` оград/мостов по потокам** — не взято: 4+15 мс, шум.
- **Пофильтрованный/поточный graph-узел сшивки** (граф-узлы 0.02, пары
  швов 4.5, узлы сетки 0.5) — дешёв и так; глобальный граф не трогать.
- **union 307** — общий тайловый примитив (`push_union`/`union_of`, его
  двухуровневое слияние уже отвергнуто замером); плотная клетка — пунктир
  разведки 15, если полимеш снова окажется у стены.
- **stitched живьём −17…−63 против −56 в соло-бенче**: reorder-вычисление
  делит ядра с соседними лейнами; bake живьём, наоборот, −98 против −80 —
  ранние фазы лейна делят ядра меньше. Шум живых фаз ±8–15 %, пара —
  построчно.
