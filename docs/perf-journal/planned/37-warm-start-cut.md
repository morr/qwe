# Запланировано 37 — разрез тёплого старта целиком: whole set по лайнам и фазам, фикс крупнейшего куска ≥150 вне замороженных стен

## Проблема

Приоритет: **1** — заезд 39, разрез-заезд по свежему рейтингу записи 48.
Дорожная лайна закрыта заездом 38 (записи 40–48: все стены разрезаны,
крупные куски — насыщенные параллели, замороженные якоря или ниже
планки). Следующий уровень — **вне дорожной лайны**, но свежего разреза
тёплого старта целиком нет: `map meshes: whole set` 2.5–2.6 с (Paris
тёплый), из них `roads in` 2.5 — дорожный лейн сидит на стене, а стены
остальных лайн и серийный префикс сборки на текущем коде не измерены.

Что известно по лайнам `build_world_meshes` (`src/map/prepare.rs`):

- **buildings** — после фикса записи 31 бенч 1461.9 (наземные тени 722,
  порядок 112, roof shadows 326, экструзия 243, развёртки 57), лейн
  живьём 2.5 при стене 3.4–3.6 — тогда «вышел из стены с отрывом в
  секунду». С тех пор стена опустилась до 2.5 — здания могли догнать.
  Свежего разреза нет.
- **small** (parking layout, surfaces, деревья, рельсы, машины) — свежего
  разреза нет; паркинг печатает свою строку, остальное — вслепую.
- **fences** — 1.2–2.3 с (записи 17/19), строится в потоке загрузки —
  скрыта под стеной roads.
- **polymesh** — `None` при выключенной панели Navmesh (стартовый
  дефолт), 0.
- серийный префикс (`set_lane_width`, `compose_trees`) и spawn/join
  (whole set − max лайн) не измерены.

Цель: **whole set вниз**. Первый шаг — разрез whole set по лайнам и
фазам; второй — фикс крупнейшего куска ≥150 мс wall вне замороженных
стен и насыщенных параллелей.

## Направление — разрез по лайнам и фазам, фикс крупнейшего ≥150

**Разрез** (временные `eprintln`; таймеры вносятся руками — патчи разреза
прошлых заездов на изменённый код не накатываются, урок записи 44; свой
патч в `/tmp/perf39-drill.patch`, держать, пока правка не закоммичена,
урок записи 42):

- лайны уже печатают свои стены (`timed()` в `prepare.rs`); добавить:
  серийный префикс сборки (`set_lane_width`, `compose_trees`) и
  spawn/join (whole set − max персональных стен — урок записи 47:
  одноуровневый пул ≈ max стены + spawn/join, вложенный конвейер прячет
  серийные стадии);
- фазы **small_lane** (`src/map/prepare.rs::small_lane`): surfaces
  (`mesh_surfaces` + chunking), деревья (`mesh_game_trees`), рельсы
  (`mesh_rails` × ступени), машины (`cars::place`); паркинг печатает
  свою строку уже;
- фазы **buildings lane** (`src/map/buildings/mod.rs::mesh_buildings`):
  по номенклатуре записи 31 — наземные тени (union/fill), порядок,
  roof shadows, экструзия, развёртки/арки;
- фазы **fences lane** (`src/map/fences.rs::entry_layers` — шаг + свипы);
- wall каждой лайны против **суммы её фаз** — GAP показывает
  не тированную сантехнику; whole set против max лайн + префикс;
- соло-бенч `map_meshing paris` ×3 (свои живые процессы заглушены —
  урок записи 42) и живой прогон ×3 тёплых перезагрузки Парижа — фазы
  под контеншном соседних лайн, как живьём.

**Фикс** — крупнейший кусок ≥150 мс wall вне замороженных стен и
насыщенных параллелей; шаблон по прецедентам краски 40 / ленты 42 /
зелени 44 / обочин 46 / замыкания 48: чанки + частичный вклад куска +
одним пулом `in_parallel` + раскладка аппендами в исходном порядке;
**чанки, не по-штучные аккумуляторы** — урок записи 42. Выходы обязаны
остаться бит-в-бит: счётчики **обеих** строк `road meshing:` (5 987 588
/ 4 232 084 verts, paint 26 729 lines / 675 836 verts, lawn scraps
11 511 / 4 064, gores 92) — контроль на то, что дорожная лайна не
задета, плюс счётчики строк своего лайна (зданиевые строки бенча,
отчёты surfaces/trees/rails/cars). Фикс, меняющий `MapData`, дёргает
`SNAPSHOT_VERSION`.

**Правило выхода** (заезды 29–38): рычаг в замороженных файлах
(`map/inspect.rs`, `map/osm/download.rs`, `src/loading.rs`,
`map/osm/model.rs`, `map/osm/model/trees.rs` — запись 30) или в
замороженных стенах выше, или крупнейший кусок <150 мс wall —
плато-отметка в этой спеке и записи 49, следующий уровень по свежему
рейтингу. Если крупнейший кусок лежит в лайне **под стеной** (не
критический путь) — фикс берётся по планке (прецедент записи 31), но
whole set он не двигает: отметить в вердикте, выигрыш — CPU и запас.

## Ожидание и риски

- whole set = max лайн + spawn/join; roads 2.5 на стене → fixed лайны
  ниже 2.5 whole set не двигают. Реальная цель заезда — найти лайну,
  догнавшую стену (кандидат — buildings, 2.5 по записи 31), либо
  зафиксировать плато тёплого старта на текущем уровне кода.
- Фазы лайн под контеншном шумят межпрогонно (записи 44/46: 619–861) —
  медианы 3 прогонов; соло-бенч для CPU-чисел.
- Если стены зданий и дорог сравнялись, фиксы зданий двигают whole set
  только при отрыве стены от второй лайны — иначе выигрыш делится
  дележом ядер.
