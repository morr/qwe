**Было.** Стена whole set после записей 24/25/26 — `roads (verge step 0)`:

**Атрибуция.** Разрез в три раунда:

2. **Внутри доминантов**: scraps — `find` 431 wall / **4300 CPU** (13 953
   газона, параллель насыщен — переписывание правил, решение записи 24 в

3. **Внутри mouths и краски**: union лент устьев **142** (6864 ленты /

**Правки — две, отдельными коммитами:**

1. **`medians::draw` по потокам** (`roads/medians.rs`): разделительные
   друг от друга не зависят — входы только читаются; вклад несёт свои
   частичные слои (четыре сборщика) и списки, `in_parallel`, слияние в
   порядке разделительных — порядок треугольников и списков тот же, что у
   серийной укладки (прецедент обочин записи 24). Каждая укладка прохода
   ставит раскладки полос себе сама (`push_paved`/`push_bed`/`push_caps`),
   полигоны кладутся через `push_shape`, который состояние билдера не
   читает, — частичные сборщики воспроизводят серийные байты. Замыкания
   `MedianInputs` получили `+ Sync`. 267 → **53**.
2. **Union устьев по клеткам** (`roads/gores/mouths.rs`): один
   `simplify_shape` по всем лентам односторонних проезжих частей —
   разложение как у теней: клетка 512 м объединяет свои ленты
   (`in_parallel`), выходы клеток объединяются разом, **дыры ищутся только
   по итоговому объединению** — дыра, разрезанная границей клетки, была бы
   двумя кусками с лишней стороной, и фильтр площади устье потерял бы.
   Клетки сортированы по ключу — результат функция входа; малый вход
   (тесты, витрины) — прежний однопроходный путь. 142 → **57**, фаза
   208 → **123**.
