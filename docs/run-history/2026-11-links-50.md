## Что влито

- **`demon/horde.rs`** — `HordeSchedule { next_wave_tick, wave_index, release,
  release_origin }`, сброс `WorldStarted`-ом; `plan_wave` — чистая функция
  `(seed, номер волны)`: очаг (отсек reject-сэмплингом, скан-фолбэк), разброс
  выпуска, затишье `wave_every × (1 ± 0.25)` — из потока
  `stream(seed, Demon, HORDE_WAVE_KEY + номер)`, ключи от 2⁶³ (у решений
  пешек верхние 32 бита — номер пешки, далеко ниже 2³¹). Выпуск порциями
  `wave_len`/тик тем же `spawn_demon` — `PawnId` подряд через источники.
  Кап общий: волна коммитит `min(wave_size, свободное)`, очередь выпуска
  считается обязательством (`pending()`, фон проверяет `spawned + pending`).
- **`WarpOrigin`** — `#[require]` у `Demon`; блуждание «от происхождения»
  (портал/очаг волны); для порталальных вектор `away` и броски бит-в-бит
  прежние (пины эквивалентности в horde.rs).
- **Фон**: интервал дефолт 1.0 → 0.03 с (кап 3500 за ~110 сим-с — директива
  владельца), кап 350 → 3500, потолок слайдера 5000.
- **Панель**: Wave size / Wave every / Wave length в секции Demon;
  `sim/horde_ms` в разрезе и SPIKE_PARTS; `Census.wave` в спайк-строке.
- **Реплей**: дворный HordeStyle 12/1.0/4 в `replay_app` — все четыре пина
  отпечатков (в т.ч. `a_restart_replays_the_run`) гоняются с волнами.

## Негативы, остатки и уроки (следующим звеньям)

- **Быстрый фон сломал два старых пина** (третий check ушёл в 4 прогона):
  `a_demon_born_on_a_tick...` и zero-wave пин ждали «ровно залп», а фон
  с интервалом 0.03 с выпускает демона каждые два тика. Пины, считающие
  демонов, теперь изолируют фон (интервал в потолок шкалы) или проверяют
  происхождение, а не счёт. Новые пины спавнера писать с учётом фона.
- **Очаг в дворе фикстуры вырожден**: проходимых тайлов мало, скан-фолбэк
  сводит соседние волны к одному тайлу — пин «то же зерно — та же волна»
  гнать на пустом полном навмеше, а «не в стены» — на дворе.
- **Док-твины скиллов делаются в главном чекауте, коммитятся из worktree**:
  `.zcode/skills` — симлинк на `../.claude/skills` СВОЕГО чекаута, у worktree
  он свой; правка по абсолютному пути главного ложится мимо ветки. Копировать
  файлы в worktree (cmp-проверка) и коммитить там; дубли в главном чекауте
  сбрасывать только после побайтовой сверки.
- Полный 30-мин прогон с волнами (формулировка Ф3 в плане) не гнан: actual
  1.2× = 25 мин wall; заменён 370-с штормом с волнами (числа выше) — остаток
  следующему звену по желанию.
- «Дефолт капа 3500 / интервала 0.03» не действует, пока в settings.toml
  живы префы владельца (cap 20 / interval 1.0) — это преф-механика, не баг;
  сброс панели возвращает дефолты.
