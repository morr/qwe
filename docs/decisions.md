# Журнал решений (decision log)

Глобальные решения проекта — то, что меняет **логику игры или архитектуры в целом**:
форма геймплея, масштабы и цели скорости, контракты поведения, устройство, которое
пересекает модули. Не сюда: механика одного модуля, пороги, рефакторинги.

Каждая запись: дата, кто решил (**владелец** — прямым вводом или консультацией /
**звено №N автономно**), суть, почему, что отвергнуто и почему, статус. Автономная
сессия, принявшая такое решение, **обязана добавить запись тем же коммитом, что и
код** (правило живёт в CLAUDE.md и в скилле `chain-run`). Отменённое или изменённое
решение не удаляется — получает новую запись со ссылкой на старую и статусом
«пересмотрено». На вопрос «какие решения приняты?» отвечает этот файл.

До-цепочные директивы владельца (форма звеньев, поворот в оптимизации) живут в
NOTES.md «След сессии» — это управление цепочкой, а не решения о проекте.

## 2026-11-21 — масштабирование населения ×10 (все восемь — владелец, консультация в сессии №45)

1. **Демоны ×10 = «фон + орды».** Постоянный фон одиночек + периодические волны-орды
   (очаг-район, затишья между волнами); внутри волны — прежний индивидуальный chase
   с заявками, группового разума нет. Отвергнуто: просто cap 3500 (рост плотности
   без драматургии волн).
2. **Люди — камерный LOD.** Вне экрана пешки живут дешёво (блуждание/бегство по
   направлению без поиска пути, решения реже), у камеры — полное AI. Только живой
   режим; детерминистический реплей — полный AI без камеры, контракт не тронут.
   Отвергнуто: без LOD (регулятор режет до ~2–5×), детерминированный LOD по
   плотности (выигрыш мал).
3. **Цель масштабирования — 15–30× при 200k** на крупном городе; продуктовый кап
   скорости 30× не поднимается.
4. **Трупы вечные, но запекаются.** Свежий труп — спрайты как сегодня; после осадки
   крови фоновый пекарь дописывает его в меш чанка (фиксированная сетка) и
   деспавнит три сущности. Распада и капа нет. Форма предложена владельцем.
5. **Население — новый дефолт мира**: `HUMAN_COUNT` = 200 000; всё мелкое вставляет
   свой `PopulationSize` (реплей-двор, приёмочный пример закреплены явно).
   Отвергнуто: ручка поверх дефолта 20k (цель ×10 — новый нормальный мир).
6. **Кап демонов — общий потолок живых** из всех источников; волна выпускает
   `min(wave_size, свободное место)`. Демоны бессмертны, механики ухода нет —
   при полном капе волны вырождаются в пустые затишья; трейд принят осознанно.
   Отвергнуто: орда уходит через ворп (владельцу объяснено, выбран потолок).
7. **Запечённые трупы — «точечный материал»** с полом `HUMAN_MIN_PX` и клампом по
   зуму; материал общий с дальним слоем живых. Отвергнуто: простой `ColorMaterial`
   (поле трупов тает на городском зуме, для дальнего слоя всё равно нужен второй
   материал).
8. **Единый порог городского зума 0.75** для всего: ярус LOD, дальний слой,
   сепарация, отказ wander-диспетчеризации — одна константа, один вопрос «экран
   показывает весь город?».
