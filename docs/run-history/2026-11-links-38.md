## Найдено (БЕЗ КОММИТОВ — правки кода угол не потребовал)

- **Процессный RNG**: два сайта `rand::rng()` в src — док-строка `rng.rs`
  и кнопка «новый сид» `ui/stats.rs:182` (пользовательский ввод, легален).
  Симуляция процессный RNG не читает вовсе.
- **`Instant::now()` / `Time<Real>` — все сайты классифицированы, в
  решениях тика стены нет**: инструментирование отчётов (tick_probe,
  archetype_census, лейн-репорты, `park_on(..., Instant)` — якорь отчётов);
  планирование по замыслу (регулятор `throttle_speed_to_frame_budget` — dt
  сокращается, док в sim_time.rs:769+; предохранитель `guard_frame_budget`
  — обрезает overstep в TickDebt, сам тик не меняет; SimLoad-замеры);
  экран загрузки `poll_job` (виртуальное время на паузе — Real по замыслу);
  дебаунс ползунков `settle_sun`/`settle_road_shape` (когда, не что —
  геометрия сеется координатами); визуал (камера, HUD-скорость, солнце).
- **`DevourUntil(Timer)`** тикается в FixedUpdate (`TickStage::DemonBehavior`,
  конвейер) — `time.delta()` там константный шаг, финал паузы тик-точный;
  закреплено комментарием demon/mod.rs:92–93. `pulse_devouring` — Update-
  косметика масштаба.
- **Сторожок зависшего таска** `PATHFINDING_TASK_HANG_SECS` (20 с) —
  panic по стене в живой ветке ответов (`listen_for_pathfinding_tasks`);
  детерминистическая ветка ждёт по `RetireAt`-тикам. Народный замысел
  (краш на сломанном бэкенде), не решение — не дефект.
- **Чек-лист скилла determinism сошёлся**: `WanderIndex::next` — ровно
  шесть задокументированных сайтов (human/systems 1, human/behavior 3,
  demon/systems 1, demon/behavior 1); поток размещения `(Population, 0)`
  живёт только внутри фиксированного цикла `spawn_population`
  (human/systems.rs:125).
- **Коллекции после свипа №24**: единственный новый хеш-код — `shadow.rs`
  (№35, кластеры и тайлы): все шесть HashMap-сайтов собирают в Vec и
  сортируют по ключу (клетки — `(x, y)`, кластеры — по первому члену,
  `results` разбираются по порядку входного Vec) либо разбираются по
  входному порядку; инвариант «порядок не от хеша» закреплён в коде
  дважды комментариями.
