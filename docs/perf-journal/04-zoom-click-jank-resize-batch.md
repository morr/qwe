# Запись 4 — Джанк щелчка зума: окно переписки силуэтов платило 25–42 мс за кадр

Статус: фикс. Файлы: `src/silhouette/mod.rs` · `RESIZE_BATCH` 2048 → 512 (093dee95).

Один щелчок колеса давал ~36 кадров по 25–42 мс: окно переписки размеров по 2048
спрайтов за кадр гнало конвейер спрайта (материал → bounds → extract) целиком.
512 держит кадр переписки под ~8 мс; догон растягивается с 10 до 40 кадров — рядом с
самим щелчком незаметно. Замер после фикса не изолировался чисто (фон дальнего зума
GPU-bound, см. запись 5), механика подтверждена ценой на спрайт.
