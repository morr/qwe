## Угол и что снято

- **Прямой проход**: все `.spawn(` по src вне `#[cfg(test)]`, UI и тредов
  (`scope.spawn`/task-спавны отфильтрованы по контексту). Мир:
  `spawn_layers` (один choke point — rail/cars/wagons/industry/tram/
  fences/buildings/roads идут через него), деревья, портал, пешки,
  bake/far-чанки, демоны, души, три оверлея, ходок. Без компонента
  сознательно: главная и offscreen камеры, UI-панели, vignette, лоадер
  (свой деспавн на `Live`).
- **Обратный проход**: 24 применения `DespawnOnExit` — каждая против строки
  таблицы CLAUDE.md; четыре файла, где grep находит слово, — только
  комментарии (city.rs, spatial.rs, movement/destination.rs,
  ui/navigation/mod.rs) и сам детектор.
- **Детектор**: `With<Transform>, Without<Camera>, Without<Node>` на
  `OnEnter(Loading)`. Расширение на Transform-меньшие упирается в
  ресурсы-как-сущности (0.20) — любой более широкий запрос матчит их
  пачками; граница записана в док.
- **Screenshot-сущности** (`dev.rs`): bevy 0.20 деспавнит после снятия
  (док в bevy_render + `despawn_all::<With<Captured>>`); краевой случай
  «смена города с висящим запросом кадра» — транзиентный, самозачищается.
